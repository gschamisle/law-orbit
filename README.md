# 법의 궤도

한 조문에서 시작하는 법령 연결 지도입니다. 법령·조문을 고르면 직접 인용과 역인용, 본문과 공식 출처를 함께 읽습니다.
헌법과 17개 업무 분야를 제공하는 **실험적 베타**이며, 분야별 수집·분석 범위가 다릅니다.
**[공개 사이트 열기](https://gschamisle.github.io/law-orbit/)** · [모바일 소개문](https://gschamisle.github.io/law-orbit/introduction.html)

![법의 궤도 브랜드 이미지](web/law-orbit-social-20260928.jpg)

## 시작하기

1. 분야에서 법령과 조문·항·호·목을 선택합니다. 본문 검색으로 목록을 좁힐 수 있습니다.
2. 인용 근거를 눌러 연결된 본문·시행일·공식 출처를 확인합니다. **이 조문을 중심으로 탐색**을 누르면 기준을 바꿉니다.
3. 필요한 근거를 선택해 HTML·CSV 검토자료로 내려받거나, **이 법령 오프라인 저장**으로 해당 자료를 보관합니다.

모바일은 기본적으로 페이지 스크롤을 허용합니다. 지도를 움직일 때 **지도 조작**, 마칠 때 **조작 종료**를 누릅니다. 상단에는 **전체 보기 · 전체 화면 · 지도 조작**을 표시하며, 기기의 동작 줄이기 설정을 존중합니다.

## 신규 추가 범위 — 2026-10-04

2026-10-04에 다음 세 분야의 선정 범위를 수집·검증해 공개 베타에 포함합니다. 개인정보 3개·물가 3개·보조금 5개, 총 11개 업무 사례의 실제 인용과 연결 본문을 확인했습니다. 기존 분야의 수집 자료와 판본은 보존합니다.

| 신규 분야 | 확인한 업무 질문 | 상세 범위 |
|---|---|---|
| 개인정보·공공데이터 | 공공데이터 제공·비공개, 개인신용정보 수집, 공공 AI·데이터 행정의 심의 근거를 법률 간 인용·역인용으로 찾기 | [17개 법령·규정과 사례 3/3](docs/privacy-universe.md) |
| 물가·공공요금 | 공공요금 산정·협의, 가격표시, 농수산물 수입·할당관세 | [10개 법령·규정과 사례 3/3](docs/prices-universe.md) |
| 보조금·지원사업 | 국고·지방 보조금 정산, 공시, 부정이익 환수·제재 | [14개 법령·규정과 사례 5/5](docs/subsidy-universe.md) |

개인정보·공공데이터 분야는 제공·공개·활용 근거가 여러 업무 법률 사이에 어떻게 이어지는지 찾는 데 초점을 둡니다. 개인정보 보호법의 조문과 하위 규정을 자세히 읽을 때는 전문 원문 리더 [보-편](https://privacy-law-reader.vercel.app/)도 참고할 수 있습니다. 이번 17개 문서와 세 사례는 수집 본문과 실제 인용으로 확인한 범위이며, 분야 전체의 인용 정확도·누락률이나 법적 판단을 보증하지 않습니다.

연결 수로 효용을 평가하지 않습니다. 사전에 공식 원문에서 확인한 모든 업무 사례가 수집 본문과 실제 인용으로 재현되는지 확인한 선정 범위를 공개 베타에 포함합니다. 물가의 과거 수수료 협의 고시는 현행 API 목록에 없어 현행 지도에서 제외했습니다. 보조금 분야는 기획예산처·행정안전부·국민권익위원회의 공통 규정이며 재정경제부 소관으로 분류하지 않습니다.

수집·검증 재현 방법과 기존 자료 보존 결과는 [추가 분야 점검 기록](docs/qa/candidate-domains-20261004.md)에 있습니다.

## 범위와 한계

기능 시험이나 자료 무결성 검사를 통과한 것이 법령 전체의 인용 정확도·누락률을 검증했다는 뜻은 아닙니다. 연결이 있어도 개정 의무를 확정하지 않고, 연결이 없어도 영향이 없다고 판단하지 않습니다.

별표·서식은 번호와 공식 원본을 연결하며, 본문 분석은 확인한 일부 자료에 한정합니다. 부칙·미수집 자료·의미만 비슷한 관계는 지원 범위를 확인하세요. **개정안 파일 검토는 국세의 로컬 앱에서만 지원하며 공개 웹에는 업로드하지 않습니다.**

## 로컬 실행

Python 3.13 이상과 [uv](https://github.com/astral-sh/uv)를 사용합니다. 공개 웹은 설치 없이 열람할 수 있습니다.

```bash
uv sync
uv run streamlit run app.py --server.port 8503
```

로컬 후속 개정 비교에는 Node.js 22 이상이 필요합니다. 수집 자료가 없는 분야에는 미수집 안내가 표시됩니다. 인증·수집·갱신·검증 방법은 [상세 프로젝트 안내](docs/project-guide.md)에 있습니다.
