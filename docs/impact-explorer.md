## 이번 변경

기존 개정안 파일 업로드, 번호 이동 누락 검토, 병행개정 검토는 기존 코드 경로를 유지한다.
세법 관계도에 **조문 영향 탐색**을 추가했다. 기존 공유 파서는 수정하지 않고,
저장된 인용 문구를 재해석하는 독립 `citation_scope` / `impact_explorer`를 사용한다.

직접 인용, 상위 조문 포함, 하위 조문 포함, 범위 포함, 문맥 확인, 항·호 불일치를
구분한다. 명시된 제외·한정·단서는 자동 적용/비적용을 확정하지 않고 문맥 확인으로 남긴다.
범위는 정수 목록이 아닌 구간으로 비교하므로, 중간 가지 조번호를 새로 만들어 내지 않는다.

지도와 근거 목록은 동일한 분석 결과를 사용한다. 은하는 2026-09-16에 수집한 시행일 기준
105개 법령/32,587개 연결을 사용한다. 원문 위치, 항·호·목 출처, 주변 문맥 및 시행일을 보존한다.
기존 업로드 검토의 32개 법령 인용 그래프와 병행 매트릭스는 기존 데이터 경로를 유지한다.

3D 은하는 별빛·발광·궤도·인용 방향 흐름, 선택 시 부드러운 이동, 연결 상세 패널,
키보드/터치, 움직임 정지, reduced-motion, 독립 HTML 저장을 지원한다.
법령 전체 보기에서 생략한 드문 인용과 같은 법령군의 인용도 법령 선택 시 펼친다.
공간상 거리와 배치는 관계 탐색을 위한 표현이며 법적 영향의 강도가 아니다.

## 현재 한계와 다음 단계

1. 선정한 법령 밖의 인용은 지도에서 제외하고 미수록 법령 목록에 남긴다.
2. 신설 항 비교의 개정 전·후 원문은 사용자가 입력한다. 과거 시행본을 자동 선택하지 않는다.
3. 같은 항, 전항, 서로 다른 계층을 가로지르는 범위, 목 범위 등은 추가 해석 대상이다.
4. 조문이 실제로 해당 버전에 존재하는지는 다음 단계의 원문 계층 모델로 검증해야 한다.
5. 같은 조 내부 참조는 은하에서 제외한다. 새 수집기는 조문 표제의 자기 인용도 제외한다.
6. 은하의 확장 자료와 기존 업로드 검토 자료를 통합하는 것은 후속 작업이다.
7. 정확한 연결과 개정 필요성 판단은 구분한다. 간접 관계는 별도의 명시적 단계로 확장한다.

## 신설 항 때문에 기존 범위 인용을 재검토해야 하는 경우

### 사용자 제안 사례

개정 전 A법 제2조는 제1항~제4항. B법은 제2항부터 제4항까지 인용한다.
개정으로 제5항을 신설할 때, 인용 문구 자체에는 제5항이 포함되지 않는다.
하지만 과거 인용이 제1항을 제외한 나머지를 모두 포괄했다면 인용 취지 재검토가 필요할 수 있다.

### 구현된 탐지 원칙

- 개정 전후 원문 구조를 먼저 확보한다. 현행본만 보고 '기존 마지막 항'을 추측하지 않는다.
- 신설 사건이 발생한 조문의 역인용만 대상으로 삼는다. 전 법령에 의미 추론을 돌리지 않는다.
- 개정 전 마지막 항을 끝으로 포함하던 범위/열거 인용을 우선 찾는다.
- 근거를 `기존 항 집합`, `인용 항 집합`, `신설 항`, `인용 원문`으로 남긴다.
- 자동으로 인용 범위를 늘리거나 '개정 누락'으로 확정하지 않는다.
- 검토 질문: '개정 전 제1항을 제외한 모든 항을 인용했습니다. 신설 제5항도 포함할까요?'
- 추가 판단이 필요한 근거는 신설 항의 내용과 기존 제2~4항의 공통 성격, B법의 목적·단서다.
- 의도 확인이 되기 전까지 지도에서 직접 인용과 별도의 점선 관계로 표시한다.
- 2~3항만 인용/원래 5항이 존재/완전히 별개 항 신설/삭제와 신설이 동시에 발생하는 경우를
  음성·경계 사례로 검증한다.

## 환경변수

키를 저장소에 쓰지 않는다. `start.ps1`은 사용자가 등록한 Windows 사용자 `LAW_OC`를

## 신설 항 비교 화면

- 경로: 세법 관계도 → 조문 영향 탐색 → 신설 항 범위 재검토.
- 한 조문의 개정 전·후 **전체 원문**을 각각 입력한다. 조문 표제와 ①·② 또는 새 줄의
  `제1항 내용` 형식이 필요하다. 발췌·중복·누락 번호·다른 조·개정 지시문만 있는 입력은 거절한다.
- 입력 원문, 사용자가 지정한 버전, SHA-256, 항별 원문 위치를 결과 JSON에 보존한다.
  과거 마지막 항을 저장된 인용 문구에서 역으로 추측하지 않는다. 마지막 부분을 잘라 낸
  입력인지 프로그램만으로는 알 수 없으므로 **전체 원문 입력이 전제**다.
- 기존 항의 내용과 번호가 유지되고 끝에 항을 신설한 경우에 자동 끝 경계 탐지를 적용한다.
  삭제·번호 이동·기존 내용 개정이 섞이면 연결된 인용을 구조·문맥 확인으로 남긴다.
- 인용 범위 재검토 / 문언상 신설 항 포함 / 구조·문맥 확인 / 끝 경계 후보 아님으로 구분한다.
- 종전 모든 항 또는 연속된 끝 항 묶음을 인용하면 우선 검토, 마지막 항을 포함한 불연속 열거는
  일반 검토로 표시한다. 단일 항 인용과 종전 마지막 항을 포함하지 않는 인용은 끝 경계 후보에서 제외한다.
- 우선순위는 구조 패턴이다. 신설 내용의 의미 유사도나 입법 취지를 자동 판정하지 않는다.
- 범위 재검토와 문맥 확인은 점선, 조 전체 등 문언상 포함은 실선으로 표시한다.
  같은 출처의 복수 인용이 서로 다른 상태이면 각각의 연결과 근거를 보존한다.
- 가상 A법 제2조 제5항 신설 예시를 제공한다. 실제 법령 데이터와 혼합하지 않는다.
- 비교 결과와 조문 원문을 JSON으로, 점선 관계를 포함한 은하를 독립 HTML로 저장할 수 있다.

### 범위와 후속 과제

현재 범위는 **끝에 항이 추가되는 변경**이다. 호·목 단위의 신설, 삭제·이동을 포함한 복합 변경,
실제 과거 시행본 자동 선택과 법령안에서 개정 후 전체 조문을 복원하는 작업은 후속 과제다.
기존 개정안 파일 업로드 검토는 그대로 유지되며, 새 구조 비교 화면과 자동으로 연동되지는 않는다.
은하의 저장 인용 자료는 2026-09-16 수집본이다. 입력 원문 버전과 인용 자료의 일치 여부를 따로 확인해야 한다.

## 조문을 중심으로 한 양방향 은하

- 세법 관계도 → 법령 은하 (3D)에서 법령과 조문 번호를 입력하고 **조문 연결 보기**를 누른다.
- `16`, `16의2`, `제16조제2항제1호`를 지원한다. 잘못된 입력은 이전 강조를 지우고 오류를 표시한다.
- 민트 실선은 선택 조문이 인용하는 곳, 금색 실선은 선택 조문을 인용하는 곳이다. 화살표는 인용 방향이다.
- 문맥·출처 확인은 분홍 점선이다. 방향별 필터, 점선 포함 여부, 전체 은하로 돌아가기, 근거 JSON/독립 HTML 저장을 제공한다.
- 전체 법령과 성운은 어두운 배경으로 남기고 직접 연결 조문만 전경에 둔다. 배경 점은 조문 선택 목록에 섞지 않는다.
- 같은 연결에 양방향 인용이 있으면 두 방향과 각각의 근거를 유지한다. 지도에서는 조 단위로 묶고, 정확한 인용 대상 번호는 근거에서 확인한다.
- 최소 인용 건수·배경 조문 점 수 설정으로 대상의 연결이 누락되지 않는다. 점을 많이 표시할 때는 겹치는 이름만 줄이고 모든 연결과 선택 목록은 유지한다.
- 역인용은 항·호·목과 범위를 대조한다. 나가는 인용도 출처 항·호·목으로 좁힌다. 상위 단위의 공통 문구는 검토 후보로 남긴다.
- 같은 조 내부 참조는 지도에서 제외한다. 번호를 해석하지 못한 나가는 인용은 별도 목록에 남긴다.
- 조회 결과가 없어도 조문의 부존재나 인용의 부재를 판정하지 않는다. 현재 범위는 선정한 105개 법령의 세법 관련 직접 연결이다.

## 기능 정리

입법예고 제기의견 수집·분류·보고서 기능과 전용 화면/명령줄/테스트/문서를 제거했다.
기존 생성 보고서와 사용자가 저장한 자료는 보존한다. 기본 화면은 **개정안 검토**와 **세법 관계도**이며,
법령안 파일 업로드 검토 및 신설 항 범위 재검토는 유지한다.

## 외부 법령 확장과 금융 은하

세법이 직접 인용하는 상법·자본시장법 등 외부 조문을 원문과 출처를 포함해 확장했다.
구체적인 범위, 갱신 방법 및 한계는 [국세 은하 수록 범위](law-universe.md)를 참조한다.
세법 → 외부법 인용이 세법 개정 → 외부법 동시 개정 의무라는 뜻은 아니다. 인용 방향과 변경 내용을 따로 판단해야 한다.

금융법령 은하는 공통 법령 데이터와 인용 엔진을 사용하되 별도 분야 화면으로 구성하는 것이 적합하다.
법률·시행령·감독규정·시행세칙·거래소 규정·가이드라인의 발령기관, 적용 기간, 위임 근거 및 효력을 구분해야 한다.
예컨대 보험업감독규정의 제4-44조 같은 번호는 현 파서의 제N조/제N조의M 형식과 다르다.
우선 자본시장 분야의 한정된 자료로 연쇄 변경 사례를 검증한 뒤 확대한다. 이 단계에서는 금융 은하를 구현하지 않았다.
