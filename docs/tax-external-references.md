# 국세의 미수집 인용 보존

국세 공개 자료는 `build_tax_universe(source)`로 생성한다. 이미 저장된 조문에서 명시한 미수집 법령 인용을 `external_references`에 보존하며, 대상 본문을 새로 수집하지 않는다. 기존 `build_universe(source)`의 기본 동작은 유지한다.

## 표시와 범위

- 미수집 인용은 출처 법령·조문·항호목, 인용 문구와 위치, 대상 법령·표기된 조문, 근거 식별자를 갖는다.
- `target_status=not-collected`, 대상 시행일은 빈 값이다. 미수집 대상은 수록 법령 목록, 확정 연결, 역인용에 추가하지 않는다.
- 법령 이름만 있으면 법령 전체 참조로 남긴다. 미수집 법령의 조문 범위는 원문을 보존하며 중간 조문 번호를 만들어내지 않는다.
- 원래의 수록 대상 연결과 별표·기준 참조는 유지한다. 보존된 인용 수는 법적 정확도나 영향 분석의 완전성을 뜻하지 않는다.
- 기존 공개 내보내기의 조문별 `external` 목록과 “미수집 인용·해석 확인” 표시를 사용한다. 원천의 `outside_scope` 집계는 조문별 근거를 대신할 수 없다.
- 표 구분선이나 중첩된 인용부호가 섞인 대상 법령명은 `citation_issues`에 원문·출처 위치·확인 사유로 보존한다. 해당 법령명이나 조문을 추정하여 교정하거나 공식 링크를 만들지 않는다. 같은 원문 위치에서 파생된 여러 대상은 확인 항목 하나로 모은다.
- `동법`처럼 대상이 해소되지 않은 상대 참조, `조ㆍ법`처럼 조문 나열에서 잘린 문구도 같은 확인 목록에 남긴다. 실제 법령명에 있는 숫자·공백이나 규정·조약 명칭은 이 사유만으로 제외하지 않는다.

## 재현 확인

`python -B -m unittest scripts.test_tax_external`은 법인세법16의 자산재평가법13①1, 법인세법63의 고등교육법3·초중등교육법3③ 인용, 이름만 있는 참조, 범위 인용, 수록 연결 불변성과 실제 공개 내보내기를 검사한다. 테스트 자료는 명시적으로 작성한 회귀 검증용 발췌이며 현행법 판정 자료가 아니다.

기존 bundle을 사용할 때는 저장된 `source`로 국세 그래프를 다시 생성해야 한다. 집계만 보유한 이전 bundle에 빈 확인 목록을 붙여 갱신 완료로 취급해서는 안 된다.
