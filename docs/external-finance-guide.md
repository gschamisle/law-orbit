# 수출·해외사업 금융과 KIC 위탁·운용 길잡이

## 두 진입점

- **수출·해외사업 금융 → 업무·제도 길잡이**: 수출입 자금·채무보증 / 해외사업·출자·투자 / 무역보험·신용보증 / 대외경제협력기금의 네 업무별 출발점입니다. 서로 순차적으로 거치는 절차가 아니므로 항목 사이에 절차 화살표를 표시하지 않습니다.
- **외환 → KIC 위탁·운용 길잡이**: 위탁 주체 → 계약·회수 조건 → 운용 범위·방식 → 감독·공고를 읽습니다. KIC는 기업 대상 수출금융을 공급하는 기관으로 분류하지 않습니다.

법률에 익숙하지 않은 이용자도 업무 질문에서 출발할 수 있도록 각 항목에 확인할 기준, 연결의 의미, 근거 조문을 함께 둡니다. 업무 근거·위임 구체화·사무 위탁·적용 제외·등록 또는 신고 의제를 설명에서 구분합니다. 자동 추출된 인용 관계만으로 적용 여부나 기관 권한을 단정하지 않습니다.
