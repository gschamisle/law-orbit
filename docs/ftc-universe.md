# 공정거래 — 수집·분석과 로컬 미리보기

2026-09-22 수집판. 공정거래 분야는 로컬 작업판에 추가했으며 아직 커밋·푸시·공개 배포하지 않았습니다.

## 실제로 할 수 있는 일

- **독점규제 및 공정거래에 관한 법률 제9조**에서 기업결합 관련 시행령·사건절차 규칙과 **기업결합 심사기준의 실제 문단**을 함께 확인합니다.
- **같은 법 제45조**에서 불공정거래행위 심사지침, 업종별 지침과 다른 수집 법령의 인용을 확인합니다.
- 지침을 선택하면 수집 본문과 명시적으로 인용한 근거 조문을 읽습니다. 연결을 클릭하면 본문 읽기 창이 열리고, 검토 기준 조문은 유지됩니다.
- 경쟁·기업결합 / 기업집단 / 하도급 / 가맹·유통·대리점 / 소비자·약관 / 조사·사건절차를 복수 태그로 관리합니다. 다른 세부 분야의 연결은 ‘분야 밖 관련 조문’으로 표시합니다.
- 법령 선택 목록은 정식 명칭으로 표시합니다. 공정거래와 국세·금융 등의 자료, 검색 상태는 독립적입니다.

## 수집 기준

[법제처 법령 목록 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdListGuide)와 [행정규칙 목록 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=admrulListGuide)에 공정거래위원회 기관코드 `1130000`을 지정합니다. 소관기관을 다시 검증하고 목록의 페이지·총수를 대조합니다. [기관코드 확인 출처](https://theme.archives.go.kr/next/organ/organBasicInfo.do?code=OG0000928).

13개 법률군: 독점규제 및 공정거래에 관한 법률, 하도급거래 공정화에 관한 법률, 가맹사업거래의 공정화에 관한 법률, 대규모유통업에서의 거래 공정화에 관한 법률, 대리점거래의 공정화에 관한 법률, 약관의 규제에 관한 법률, 표시ㆍ광고의 공정화에 관한 법률, 방문판매 등에 관한 법률, 전자상거래 등에서의 소비자보호에 관한 법률, 할부거래에 관한 법률, 소비자기본법, 소비자생활협동조합법, 제조물 책임법 및 해당 시행령·시행규칙을 수집합니다. 공동 소관인 제조물 책임법도 포함합니다.

행정규칙은 공개된 제목 범위와 보완 목록으로 선정합니다. 기업결합·불공정거래·동일인 판단·순환출자·부당지원·하도급·소비자보호와 사건처리 기준 등을 포함합니다. 직제·인사·보안·자문단 운영 등은 범위 밖입니다. **공정위 모든 자료의 완전 수집을 뜻하지 않습니다.** 선정·제외 목록은 수집 당시 inventory에 남깁니다.

인용 건수는 출처 위치·대상 범위별 근거 수입니다. 서로 다른 인용 문구가 같은 조문을 가리킬 수 있고, 범위·나열형 인용은 여러 대상으로 나뉩니다. 개정할 문서 수나 정확도 점수가 아닙니다.

## 문단형 지침 처리

공통 인용 분석기를 재사용하되, `Ⅰ. 목적`, `Ⅱ. 정의` 등 **실제 문단 제목과 원문 위치**를 보존합니다. 임의의 ‘제1조’를 만들지 않습니다. 지침에 명시된 법령 약칭과 시행령 정의를 사용하며, 작은따옴표 형식도 원문의 위치를 유지해 처리합니다.

문단 근거는 조문 그래프와 별도로 저장합니다. 웹 화면에서는 대상 법 조문의 역인용과 지침의 직접 인용 목록에 함께 표시하고, 전체 지도에는 실제 연결이 확인된 지침도 포함합니다. 로컬 Streamlit에서는 ‘이 조문을 인용한 지침 문단’과 ‘문단형 지침·분석 상태’에서 확인합니다.

수집 본문에 없는 조문 번호나 해결하지 못한 별칭은 연결 성공으로 간주하지 않고 해석 확인 목록에 남깁니다. 외부 법령은 인용 문구와 공식 링크만 보존합니다. 금융·국세 자료를 가져와 공정거래 자료와 자동으로 합치지 않습니다.

## 실행

프로젝트 루트에서 기존 `LAW_API_KEY` 또는 `LAW_OC` 환경변수·로컬 `.env`·Windows 사용자 환경변수를 재사용합니다. 인증값은 출력하지 않으며 Git에 넣지 않습니다.

```powershell
python -m unittest scripts.test_ftc -v
python -m scripts.collect_ftc_universe --stage inventory
python -m scripts.collect_ftc_universe --stage bodies
python -m scripts.collect_ftc_universe --stage build
```

출력은 `output/ftc-universe/`에 한정됩니다. 같은 날짜 본문 캐시는 판본·해시를 대조해 재사용하며, 검증 완료 후에만 bundle을 교체합니다. 기존 bundle은 history에 보존합니다. 실패하거나 기존 잠금이 있으면 기존 자료를 보존합니다. 이전 날짜 작업을 이어가려면 각 단계에 동일한 `--date YYYYMMDD`를 지정합니다.

기존 정적 사이트에 공정거래만 추가하는 경우:

```powershell
python -m scripts.build_ftc_site --base-site output/static-forex-finance-preview-v2 --destination output/static-ftc-preview
python -m scripts.validate_static_galaxies output/static-ftc-preview
python -m http.server 8522 --bind 127.0.0.1 --directory output/static-ftc-preview
```

미리보기: <http://127.0.0.1:8522/>. 기존 출력 폴더가 있으면 빌더는 덮어쓰지 않고 중단합니다. 새 이름을 지정하세요. 일반 로컬 앱은 `streamlit run app.py`로 실행합니다.

## 검증과 한계

- 목록 페이지 완전성, 필수 법률·규정 존재, 판본·소관·본문 일치, 모든 인용 위치와 원문 일치를 검사했습니다.
- 기존 정적 자료 **19,547개 파일**과 기존 11개 분야의 메타데이터, 외환·금융 연결을 그대로 보존했습니다.
- 공정거래 포함 미리보기: 19,806개 압축 자료, 총 19,829개 파일. 현재 무료 호스팅 파일 수 검증을 통과했습니다.
- 공정거래 파싱·범위·원문 변조 거부·본문 내보내기, 자료 미수집 안내, 화면 상태 보존과 기존 분석 기능을 검사합니다.
- Python 테스트 **66건**, JavaScript 테스트 **7건** 통과. 기존 국세·금융·조달계약·국토·환경 실제 수집 자료의 공통 엔진/웹 결과 일치 검사도 포함합니다. 전체 Streamlit의 실제 국세·금융 화면 전환 테스트 1건은 현 작업 폴더에 금융 원본이 없어 **미실행**입니다.
- 실제 브라우저에서 공정거래법 제9조 → 기업결합 심사기준, 지침 → 법 제9조의 본문 읽기, 제45조 연결, 국세/공정거래 검색·선택 상태 분리, 세부 분야 밖 연결 표시를 확인했습니다. 자료·화면 검증 결과는 `output/ftc-tests/verification.json`에 보관했습니다.

미구현: 지침 내부의 ‘Ⅱ. 3. 가.’ 등 문단 간 참조, 첨부파일·별표 표 내부·부칙의 인용 분석, 심결례·판례, 표준계약서, 의미상 관련성, 전면적인 전문가 정확도 평가, 공정거래 개정안 업로드 검토, 공정거래 자동 갱신 예약. 위법성·시장획정·과징금 계산·연계개정 의무를 자동 판정하지 않습니다. 해석 확인 목록을 포함해 원문 대조가 필요한 베타입니다.
