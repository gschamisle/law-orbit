# 보건·의료 2차 확장 검토 — 감염병·응급의료

검토일: 2026-10-06. 공개 앱에 추가하기 전의 검토 결과이며, 구현·배포는 수행하지 않았다.

## 판단

두 분야 모두 추가할 가치가 있다. 기존 보건·의료 안에 **감염병**, **응급의료** 하위 필터로 두는 구성을 권한다. 기존 의료기관·인력, 지역·공공보건, 건강보험·의료급여와 실제 조문 인용으로 이어진다.

첫 범위는 두 법률과 각각의 시행령·시행규칙, 총 6개 법령이다. 고시는 본문 수집과 판본 관계를 검증한 것부터 선정한다. 모든 질병·진료 지침으로 범위를 넓히기보다 기관 지정·시설·권한의 근거를 찾는 업무부터 지원한다.

| 분야 | 도움이 되는 업무 | 확인한 연결 경로 | 주 사용자 |
|---|---|---|---|
| 감염병 | 관리기관 지정, 격리·진료시설 기준과 근거 확인 | 감염병예방법 제36조·제39조 ← 시행규칙 제31조 → 별표 4의2, 의료법 시행규칙 제34조, 지역보건법 제13조 | 보건소, 지자체 감염병 담당자, 공공의료 담당자 |
| 응급의료 | 지역응급의료기관 지정기준·신청서식 확인 | 응급의료법 제31조 ← 시행규칙 제18조 → 별표 8, 별지 제6호·제7호서식. 법 제31조는 의료법 제3조도 인용한다. | 시·군·구 의료기관 지정 담당자, 응급의료 담당자, 병원 행정 담당자 |

표의 화살표는 원문 인용 방향이다. 앱의 역인용 탐색으로 법률에서 해당 하위규정을 찾아갈 수 있다. 직접 번호를 쓰지 않는 위임 문구 자체가 이 경로를 자동 확정하는 것은 아니다.

## 실제 분석 결과

기존 1차 수집 자료 26문서와, 공식 API에서 조회한 후보 8문서를 함께 시험 분석했다. 후보는 법령 6개와 한국 응급환자 중증도 분류기준, 한국 병원 전 응급환자 중증도 분류기준이다.

| 항목 | 결과 | 해석 범위 |
|---|---:|---|
| 후보 문서 | 8 | 공개 범위 확정이 아닌 검토 표본 |
| 후보 조문 레코드 | 545 | 삭제 조문도 포함. 유효 조문 수와 같지 않음 |
| 후보 별표·서식 메타데이터 | 160 | 전부 공식 파일 링크 있음 |
| 기존 26문서와 후보 8문서 사이 인용 근거 | 145 | 원문 인용 위치 단위. 조문·노드 수 또는 개정 의무 수가 아님 |
| 위 근거 중 문맥 후보가 아닌 조문·별표 참조로 분류된 것 | 96 | 조문 94, 별표 2. 파서 분류 결과이며 정확도 인증이 아님 |

후보 문서의 식별자·시행일·발령기관과 원문 인용 위치를 확인했고, 조문·별표 연결 그래프의 구조 검증을 통과했다. 기존 1차 자료는 2026-09-29 수집 기준이며, 후보는 2026-10-06 조회 기준이다. 모든 문서를 같은 날 다시 수집한 결과는 아니다. 미래 시행 판본을 포함한 전수 연혁 검증은 이번 검토 범위에 포함하지 않았다.

감염병 시행규칙 별표 4의2와 응급의료 시행규칙 별표 8은 파일 요청의 HTTP 200 응답과 PDF 파일 식별자를 확인했다. 나머지 158개의 접근 성공을 전수 확인하거나 별표 안의 내용을 새로 해석한 것은 아니다.

- [감염병 시행규칙 별표 4의2 PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=160560265)
- [응급의료 시행규칙 별표 8 PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=167218609)

현재 자료만 보면 응급의료의 명확한 외부 조문 인용 10건 중 9건은 정의 조문이다. 그러나 새 법령군을 포함한 시험 분석에서는 기관 지정 → 하위규정 → 별표·서식 경로가 실제로 확인됐다. 이 업무 경로를 앞에 두는 것이 유용하다.

## 먼저 해결해야 할 문제

### 1. 법령명을 생략한 후속 조문의 소속

기존 공공보건의료에 관한 법률 시행규칙 제2조의2는 감염병예방법 제8조의2를 인용한 뒤 같은 법의 제36조를 이어서 인용한다. 현재 파서는 뒤의 제36조를 자기 시행규칙으로 귀속해 대상 조문 없음 목록에 넣는다.

신규 후보인 한국 병원 전 응급환자 중증도 분류기준 제1조에서도 `동법 시행규칙 제18조의3제5항`의 상대 법령명 해석이 미해결로 기록됐다. 앞서 등장한 법령명을 어디까지 이어받을지, 법률·시행령·시행규칙을 어떻게 구분할지 실제 사례로 보완해야 한다.

### 2. 존재하는 번호라도 옛 조문일 수 있음

응급환자 중증도 분류 조문은 2026-06-05 개정에서 시행규칙 제18조의3에서 **제18조의4**로 이동했다. 현재 제18조의3은 응급의료기관 재지정 절차에 관한 조문이다.

그런데 이번에 조회한 한국 응급환자 중증도 분류기준 제1조는 여전히 시행규칙 제18조의3을 인용한다. 한국 병원 전 응급환자 중증도 분류기준도 같은 옛 번호를 인용한다. 첫 고시의 인용은 대상 번호가 존재한다는 이유로 현재 그래프에서 일반 연결로 처리된다.

**원문 인용을 보존하고, 조문 이동·판본 확인이 필요한 연결로 표시해야 한다.** 번호를 제18조의4로 조용히 바꾸거나, 다른 내용의 현행 제18조의3을 정상 연결로 보여서는 안 된다. 조문 이동 이력을 확인한 후보를 안내하되 자동 법적 판단으로 제시하지 않는 설계가 필요하다.

- [한국 응급환자 중증도 분류기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000234560)
- [한국 병원 전 응급환자 중증도 분류기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000270800)

## 권장 작업 순서

1. 법령명을 생략한 연속 인용과 `동법 시행규칙` 해석 보완. 기존 분야에 대한 회귀 검증을 함께 수행한다.
2. 두 법률·시행령·시행규칙을 보건·의료에 추가하고, 감염병·응급의료 필터와 대표 업무 경로를 구성한다. 별표·서식은 연결 대상 번호와 원본 바로 열기를 제공한다.
3. 옛 조문 번호·이동 이력의 확인 표시를 먼저 갖춘 뒤, 검증한 고시를 추가한다. 감염병관리시설 평가 고시와 신고 진단기준 고시는 별도 본문 수집·파싱 검증 후 결정한다.

별표 안의 모든 문구를 연결하거나 임상적 중증도, 시설의 기준 충족 여부, 개별 상황의 조치 적법성을 판정하는 기능은 이번 확장에 포함하지 않는다.

## 검토 자료

공개 코드와 운영 수집 자료는 수정하지 않았다. 시험 분석 파일은 공개 수집 폴더와 분리한 `output/healthcare-phase2-review-20261006/`에 보관했다.

- `candidate-source.json`: 검토 후보 8문서의 공식 원문·식별 정보
- `candidate-graph.json`: 기존 26문서와 후보를 함께 분석한 그래프
- `report.json`: 판본, 수치, 대표 조문, 별표 링크, 파일 접근 표본 결과

후속 구현에서 이 파일을 운영 데이터로 그대로 승격하지 말고, 인용 오류를 보완한 뒤 확정 범위에 맞춰 재수집·검증한다.
