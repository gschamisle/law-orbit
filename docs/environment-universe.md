# 환경화학안전 은하

**법령은하 → 환경화학안전**에서 환경관리 / 화학물질 / 화학사고·안전 / 전체 연결을 탐색한다. 기존 다섯 은하와 자료·캐시·검색·선택 상태를 분리하며, 공통 수집·인용 분석·3D 렌더링 코드를 재사용한다.

인용 근거는 출처 위치와 대상 조문별 건수다. 범위 인용은 여러 조문으로 펼쳐지므로 고유한 문장 수나 개정 의무 수와 다르다.

### 수집 범위

- 환경관리: 환경정책기본법, 환경영향평가법, 환경오염시설법, 대기환경보전법, 물환경보전법, 폐기물관리법, 토양환경보전법, 환경보건법, 잔류성오염물질 관리법, 환경오염피해구제법.
- 화학물질: 화평법, 화학물질관리법, 생활화학제품법과 관련 등록·평가·표시·승인·조사 고시.
- 화학사고·안전: 화학사고예방관리계획서 작성·검토·이행 규정, 산업안전보건법, 산업안전보건기준규칙, 공정안전보고서규정, 위험물안전관리법, 고압가스 안전관리법, 선정한 유해화학물질 시설 기준.
- 법률 16개 계열의 시행령·시행규칙을 포함한다. 복수 분야 태그를 쓰며 선택 분야 밖의 실제 인용·역인용도 원문 근거와 함께 표시한다.

법령은 API의 공식 약칭을 우선 사용한다. 일부 긴 행정규칙에는 화면용 짧은 이름을 쓴다. 이 이름을 새로운 인용 별칭으로 추정하지 않으며 정식 명칭, 공식 판본 링크, 시행일은 원문 정보에 유지한다.

## 살펴볼 조문

- **화학물질관리법 제23조**: 수집 범위의 역인용 49건. 화학사고예방계획 규정, 산업안전보건법 시행령, 위험물안전관리법 시행규칙 등과 연결된다.
- **화평법 제10조**: 역인용 106건. 등록·평가 제도의 하위 규정과 관련 법령을 살펴볼 수 있다.
- **환경오염시설법 제6조**: 인용 9건, 역인용 78건.
- **화학사고예방관리계획서 작성 등에 관한 규정 제17조**: 공정안전보고서 규정에 대한 실제 인용 근거를 확인한다.

수치는 해당 판본에서 문맥 확인 후보를 포함한 값이며 화면 필터에 따라 달라진다. 법령마다 정의·적용 대상·시설·수량 기준이 달라 같은 물질을 언급한다는 이유만으로 동일 규제라고 판단하지 않는다.

## 시행예정판·공식 응답 차이 처리

행정규칙 현행 목록 API가 같은 ID의 현행판과 공포된 미래 시행판을 함께 반환하는 사례를 확인했다. `인체급성유해성물질, 인체만성유해성물질 및 생태유해성물질의 지정고시`는 2026-07-01 시행판을 본문 분석에 사용하고, 2026-12-17 시행예정판은 자료 안내의 별도 목록에만 보관한다. 서로 다른 현행판이 같은 ID로 충돌하면 계속 실패 처리한다.

환경오염피해구제법과 시행령·시행규칙은 목록에서 기후에너지환경부만 표시하지만, 동일 ID·시행일의 공식 본문에는 중앙환경분쟁조정피해구제위원회가 함께 표시된다. 이 3개 명칭의 정확한 기관 조합에 한해 추가 기관을 검증·기록한다. 다른 법령이나 다른 기관 불일치는 허용하지 않는다.

수집 결과는 `output/environment-universe/` 아래에만 저장한다. 기존 세법·금융법·지방세·조달계약·국토건축주택 원문을 덮어쓰거나 합치지 않는다. 기존 세법·금융법 자동 갱신 예약은 유지하며 **새 은하의 자동 갱신은 아직 연결하지 않았다**.

## 구현·검증

추가 파일은 `core/environment_collection.py`, `core/environment_universe.py`, `ui/environment_map_ui.py`, `scripts/collect_environment_universe.py`, 두 환경 분야 테스트 모듈이다. 공통 화면에 여섯 번째 프로필을 연결하고 인용 분석기의 명시적 별칭 지원을 환경 분야에도 적용했다.

신규 단위·통합 테스트 22개는 현행·예정판 분리, 기관 검증, 별칭·범위 인용, 직접 인용·역인용, 분야 밖 연결, 자료 미수집 시 대체 금지, 여섯 은하의 상태 분리, 기존 업로드 위젯 보존을 확인한다.

실제 판본 통합 테스트는 Git에 포함하지 않는 로컬 수집 자료가 있어야 실행된다. 깨끗한 체크아웃에서는 해당 테스트가 이유를 표시하고 건너뛰며, 고정 입력 기반 테스트와 미수집 상태 테스트는 그대로 실행한다. 자료가 있는데 검증에 실패하면 건너뛰지 않는다.

최종 결과와 보호 파일 해시는 `output/environment-universe/verification.json`, 로컬 전체 테스트는 `regression-final.log`, 수집 자료가 없는 체크아웃 테스트는 `clean-check-final.log`에 기록한다.
