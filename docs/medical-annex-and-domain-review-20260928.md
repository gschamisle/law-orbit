# 별표 분석 보완 및 고용·노동·물가·지방조달 검토

검토일: 2026-09-28. 구현한 공통 분석·선택 UI와 신규 분야의 타당성 검토를 구분한다. 공개 배포와 신규 분야 전체 수집은 이번 작업에 포함하지 않았다.

## 1. 의료 별표: 공통 분석 기반 구현

`core/annex_analysis.py`를 추가했다. 기존 `build_universe`에 `annex_bodies=True`를 지정하고 별표에 검증된 `body_analysis`를 넣으면 별표 본문의 명시적 인용도 그래프에 포함된다. 기본값은 기존 동작을 유지한다.

- API의 여러 열 표를 행·칸으로 분리하고, 칸 순서로 합친 내용을 HWP 원문과 공백 제외 대조한다. 다른 칸에서 등장한 법령명·별칭을 가져오지 않는다.
- HWP의 여러 칸 표를 검증 없이 평문으로 분석하지 않는다. 단일 칸에 담긴 문단은 번호·목·비고 위치를 보존한다.
- HWPX는 파일 시그니처, 문단·줄바꿈·칸 주소·병합 정보를 읽는다. 중첩 표는 미분석으로 남긴다.
- 인용 근거에 별표 번호, 칸/문단 위치, 추출 본문 내 시작·끝 위치, 원본 파일 및 추출 본문 해시를 기록한다.
- 미수집 외부 법령은 공식 링크와 미수집 상태를 남긴다. 본문이나 역인용까지 검증했다고 표시하지 않는다.
- 표 내부의 '종합병원과 같음', '제2호다목' 같은 상대 참조, 병합 칸의 기관 귀속, 정원·면적 산식은 자동 확정하지 않는다.

### 실제 표본 검증

의료법 시행규칙 별표 3(시설기준), 4(시설규격), 5(의료인 정원), 진료지원업무 수행행위 목록 고시 별표: 총 4개, 칸·문단 266개.

| 확인 항목 | 결과 |
|---|---|
| 수집된 대상 법령으로 연결한 별표 본문 인용 근거 | 12건 |
| 표본 범위 밖 법령의 인용 근거 | 14건, 미수집 표시 |
| 정원표 → 의료법 제43조 | 9곳, 제1·2·3항 각 3곳 |
| 의료법 제43조에서 정원표를 역인용 조회 | 같은 9곳 모두 확인 |
| 원문 위치·인용 문자열 일치, 중복 근거 ID, 입력 자료 불변 | 통과 |

26건은 인용이 나타난 위치의 수이며, 법령 수나 서로 다른 대상 조문 수가 아니다. 정확도·재현율을 전체 의료 법령에 일반화할 수 없다.

재현: 같은 폴더의 Python 환경에서 `python -m scripts.verify_medical_annexes`. 표본 원본은 `output/medical-annex-feasibility-20260928`, 결과는 `output/medical-annex-analysis-20260928`. 대상 본문 캐시가 없을 때만 `--collect-targets`를 사용한다. 이 스크립트는 기존 분야의 활성 자료를 변경하지 않는다.

**후속 구현:** 의료기관 개설·운영 범위의 8개 문서·492개 조문을 수집하고 의료 메뉴, 별표 본문 읽기·인용 위치·검토자료 내보내기를 로컬 미리보기에 연결했다. [의료 분야 구현·검증 안내](medical-universe.md). 의료 분야 전체 수집, PDF·이미지 전용 표, 모든 표 형식, 내부 참조 완전 해석, 산식/적합성 판단은 여전히 미구현이다.

공식 표본: [의료법 시행규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=286963&efYd=20260612), [진료지원업무 목록 고시](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000282180). HWP 구조 확인은 [한컴 파일 형식 5.0 명세](https://cdn.hancom.com/link/docs/한글문서파일형식_5.0_revision1.2.pdf)를 따른다.

## 2. 공개 웹앱: 직접 입력 대신 선택

- 법령 이름 검색칸과 조문 번호 입력칸을 제거했다. 법령·조문은 목록에서 선택한다.
- 항·호·목 선택 목록은 수집 본문의 실제 번호 구조에서 만든다. 인용문 안의 번호를 새 항목으로 만들지 않는다.
- 조 번호를 모를 때 본문의 단어로 목록을 좁히는 기능은 '본문에서 찾기'에 접어 남겼다.
- 저장된 세부 범위는 유지한다. 본문에서 확인되지 않는 범위는 '저장된 범위, 원문 확인'이라고 명시한다.

**달라지는 점:** 임의 번호, 여러 항을 조합한 범위를 새로 타이핑할 수 없다. 긴 법령 목록은 스크롤이 필요하다. 수집되지 않은 조문은 선택할 수 없다. 인용문 자체에 기재된 범위 인용을 분석하는 기능은 그대로다. 로컬 Streamlit의 개정안 검토 입력 화면은 이번 변경 대상이 아니다.

## 3. 지방조달: 독립 분야 추가보다 기존 공백부터

현행 조달 분야에는 지방계약법·시행령·시행규칙과 지방계약 분류가 이미 있다. 법제처 API를 다시 조회한 결과 다음 두 예규는 2026-07-01 시행 판본의 본문 텍스트가 0자이고, 전문 PDF 첨부파일만 제공된다.

- [지방자치단체 입찰 및 계약 집행기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000281382)
- [지방자치단체 입찰시 낙찰자 결정기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000281396)

우선순위는 이 두 PDF의 장·절·항목·쪽 위치를 보존한 본문 추출과 명시적 인용 분석이다. 평가표·점수표는 문단 분석과 별도로 검증해야 한다. 이번에는 첨부 제공과 미분석 상태까지 확인했으며 PDF 분석기를 구현하지 않았다.

국가계약과 지방계약을 수의계약·입찰참가자격·낙찰·계약변경·제재 등의 주제로 나란히 보는 것은 유용하다. 비슷한 문구는 비교 후보로 표시하고, 실제 직접 인용과 구분해야 한다. 서로 일치한다거나 한쪽 개정이 다른 쪽 개정 의무를 만든다고 자동 단정하지 않는다. '제도가 맞춰지는 추세' 전체에 대한 연혁 비교는 미실행이다.

## 4. 고용·노동: 추가 권장

근로기준법·기간제법에 대한 실수요가 있으므로 독립 분야로 만들 가치가 있다. 소관부처가 아닌 부처의 정책협의·업무 파악에도 활용할 수 있다. 소관 정보는 공식 자료대로 유지한다.

실제 API에서 현행 판본 8개(근로기준법·시행령, 기간제법·시행령, 파견법, 최저임금법, 근로자퇴직급여 보장법, 노동위원회법)를 별도 표본 수집했다. 공통 분석 결과 내부 인용 근거 972건과 외부 인용 근거 223건이 생성됐다. 이 숫자는 문맥 확인 후보와 같은 법 내부 인용 등을 포함한 결과이며, 검증된 연결 정확도나 개정 필요 건수는 아니다.

| 시작 주제 | 출발점 | 얻을 수 있는 것 |
|---|---|---|
| 적용 범위 | 근로기준법 제11조 | 시행령 및 적용 범위 별표로 이어지는 근거 |
| 근로시간·휴가 | 근로기준법 제50조·제60조 | 같은 법의 예외·특례와 파견법 등 연결 |
| 기간제 사용 | 기간제법 제4조 | 시행령의 사용기간 예외 관련 조문 |
| 차별시정 | 기간제법 제8조·제9조 | 신청·시정 절차, 노동위원회법·파견법 연결 |
| 근로계약 | 기간제법 제17조 | 서면명시 의무와 제재 근거 |

이번 표본에서 기간제법 제4조로 들어오는 시행령 인용 4곳, 제9조와 노동위원회법·파견법 사이의 연결이 실제 확인됐다. 다음 수집은 각 법령의 하위법령·관련 행정규칙을 보완하고, 근로기준법 시행령의 적용 범위 별표를 검증하는 순서가 좋다.

**경계:** 갱신기대권, 근로자성, 통상임금, 해고 정당성, 차별 비교대상 등은 조문 연결만으로 결론을 낼 수 없다. 판례·행정해석은 출처·선고/회신일·적용 판본을 별도로 붙이는 후속 작업이다. 개인별 노동상담 자동판정으로 소개하지 않는다.

확인한 공식 판본: [근로기준법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=283457&efYd=20260820), [기간제법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=232201&efYd=20210518). 상세 표본은 `output/domain-review-20260928/research.json`.

## 5. 물가: '협업 업무별 법적 수단'으로 추가 검토 권장

물가안정법·시행령과 관련 법률의 현행 원문을 확인했다. 물가안정법만으로도 공공요금 협의, 가격표시, 최고가격, 긴급수급조정, 매점매석 금지라는 구체적인 진입점이 있다. 특히 제4조는 주무부장관과 재정경제부장관의 협의가 직접 규정되어 있어 사용자가 말한 협업형 업무에 잘 맞는다.

| 업무 질문 | 시작 법령·조문 | 연결 방식 |
|---|---|---|
| 공공요금 변경 때 어떤 협의가 필요한가 | 물가안정법 제4조, 시행령 제6조 | 협의 근거와 요금별 개별 법령의 결정 권한을 함께 열람 |
| 가격 급등·공급 부족에 쓸 수 있는 수단은 무엇인가 | 물가안정법 제2조·제6조·제7조 | 법률·시행령·시행 중인 개별 고시의 근거·기간 확인 |
| 가격표시는 누가 명하고 무엇에 적용하나 | 물가안정법 제3조 | 시행령·가격표시 관련 고시 확인 |
| 농산물 수급·수입 대책의 근거는 어디에 있나 | 농안법 제5조·제13조·제15조 | 수급계획·비축·수입 추천과 관세 분야 연결 |
| 할당관세와 수급조절은 어디서 연결되나 | 농안법 제15조제5항 → 관세법 제71조 | 원문에 있는 명시적 인용; 실제 적용 품목·기간은 별도 대통령령/별표 확인 |

공정거래의 가격담합, 관세의 할당관세 등 기존 분야는 자료를 중복 수집하기보다 필요한 조문을 연결해서 읽게 한다. 주제가 같다는 이유만으로 인용선을 만들어서는 안 된다. 명시적 인용, 법정 협의 관계, 편집자가 묶은 업무 참고자료를 구분하는 설계가 필요하다.

처음부터 전기·가스·교통·통신·농축수산물 법령 전체를 한 지도에 넣는 것은 권하지 않는다. 먼저 위 질문에 답하는 경로를 검증하고 필요한 법령을 단계적으로 추가한다. 물가 전망, 가격 인상의 타당성, 정책 효과를 판단하는 앱은 아니다.

공식 근거: [물가안정법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=276105&efYd=20260102), [시행령](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=288771&efYd=20260818), [농안법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=283749&efYd=20260828), [관세법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=288689&efYd=20260811), [재정경제부 조직도](https://mofe.go.kr/mi/orgnzt/org.do?bbsId=MOSFBBS_000000000097&menuNo=9040100).
