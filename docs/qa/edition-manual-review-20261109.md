# 2026-11-09 판본 갱신 검토

기준 공개 자료는 `e3fc10ebd21db4a66a97`이다. 이번 주 새 차이 중 공식 목록·고유번호·판본번호·시행일과 본문을 대조한 **판본 변경 63건과 표기 정정 1건**을 반영한다. 이전부터 남아 있던 전체 미반영 목록을 일괄 최신화한 결과는 아니다.

## 시행 예정판이 현행 목록에 먼저 나타나는 경우

`증권의 발행 및 공시 등에 관한 규정`(고유번호 `36044`)의 대표 목록 항목이 2026-11-13 시행 예정판 `2100000287734`로 바뀌었다. 기존 갱신기는 이 항목을 예정판으로 제외하면서 현재 적용되는 문서 수가 280개에서 279개로 줄었다. 범위 축소 검증이 이를 차단해 기존 금융 자료는 보존됐다.

갱신기는 이제 공식 연혁의 페이지와 건수를 대조하고, 같은 고유번호에서 점검일에 시행 중인 판본을 선택해 해당 판본의 본문을 직접 확인한다. 11월 9일에는 2026-07-28 시행판 `2100000283270`을 유지하고, 11월 13일 예정판 정보는 따로 보존한다. 이전 저장 파일을 근거 없이 현행으로 간주하는 방식은 사용하지 않는다. 연혁 누락·모호한 중복·확인할 수 없는 폐지 등은 기존 자료를 보존하고 검토 대상으로 남긴다.

이 선택은 API의 판본 시행일 기준이며 부칙의 개별 조항별 특례 시행일을 모두 해석한 결과가 아니다.

근거: [7월 28일 판본](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000283270), [11월 13일 예정판](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000287734).

## 중앙 법령·행정규칙 6건

지방조달 두 지침은 새 API 본문이 비어 있고 공식 PDF 첨부로 제공된다. 새 첨부의 파일·추출문 해시를 판본과 결속하고, 새 파일의 문단·표 셀·명시적 내부 참조를 다시 분석한다. 옛 PDF 주소·분석·페이지별 검토 메모를 새 판본으로 그대로 이월하지 않는다. 점수·금액·산식이나 표의 행·열을 결합한 적용조건은 판정하지 않는다.

나머지는 지방세 지역 자료에 포함된 조례·규칙의 판본 변경 57건이다. 보령시 보령문화의전당 관리·운영 조례 시행규칙은 `·`와 `ㆍ`의 표기 차이만 정정하며, 새 개정으로 집계하지 않는다. 지방조달 집행기준의 띄어쓰기 변화도 고유번호를 유지한다.

구미시 도시숲 조례는 32개 조문에서 24개로 줄었다. 공식 XML의 2026-11-04 제2153호 **전부개정** 정보와 제1조부터 제24조까지의 본문을 대조했으며, 파서가 조문을 누락한 것으로 처리하지 않는다.

새 PDF 표본 점검에서 `건설산업 기본법 시행규칙`처럼 명칭 내 공백이 있는 다른 법의 하위법령을 지침의 `시행규칙` 약칭으로 오인하는 사례를 발견했다. 명시된 법률명·하위법령을 우선하고 수집 목록에서 정식 명칭을 확인할 수 없는 경우는 연결을 보류하도록 보완한다. 원문의 공백·위치·문구는 고치지 않는다.

최종 전수 재검증에서 낙찰기준의 오귀속 7건과 집행기준의 불확실한 연결 7건을 확인 필요로 남겼다. 나머지 인용 1,220건은 원문 위치·페이지·해시·대상 등 기존 증거의 모든 필드가 동일하다. 내부 참조 337건도 새 추출문에서 생성했다. 이 수치는 인용 발생 수이며 개정할 조문 수를 뜻하지 않는다.

## 보류와 범위 한계

- 남원시 주차장 조례의 2026-11-06 판본 `2183037`: 공식 XML에서 부칙의 제1조·제2조가 본문 조문으로 섞여 번호가 중복된다. 중복 조문을 임의 삭제하지 않고 기존 공개 자료를 보존한다.
- 이번에 새로 발견된 시행 예정 10건은 현행 본문으로 교체하지 않는다.
- 고령군 저탄소 녹색성장 조례는 현행 목록에서 확인되지 않은 상태이며, 이를 폐지로 단정하지 않는다.
- 이번 두 지방조달 PDF 외 별표·첨부파일 본문 전체의 변경 조사, 미수집 법령의 신규 제정 여부, 법적 효과의 자동 판정은 이번 검증 범위에 포함하지 않는다.
