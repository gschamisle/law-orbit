사용 목적을 먼저 고정하고, 실제 공식 문구로 다음 사례를 확인했다. 유사한 규정이나 키워드 태그는 인용선을 만들지 않는다. 새로운 범위는 기존 자료를 교체하지 않는 로컬 미리보기로 구성한다.

## 수집 중 발견한 범위 오류와 보완

1. 개인정보 보호법 시행규칙은 폐지되어 수집하지 않는다. 현행 AI·데이터 행정법 시행규칙은 포함한다. 2027년 시행 예정인 법 제32조와 시행령 제26~29조는 현행 API 본문에 들어 있지 않음을 확인했다.
2. 수수료 협의대상 및 방법 고시는 공식 API `nw=1` 현행 검색에서 없고 `nw=2` 연혁에만 있다. 현행 범위에서 제외하고 공식 연혁 확인 링크만 별도 안내한다. 폐지 여부를 이 검색만으로 단정하지 않는다.
3. 공공요금 산정기준은 문단형이므로 `Ⅶ. 요금검증 / 6.` 위치를 표시하고 조문 번호를 만들지 않는다. 해당 문단의 따옴표 없는 정보공개법 전체 참조는 수집한 정식 법령명과 명시적 법률 참조 표현을 함께 확인한 경우에만 연결한다. 정보공개법의 특정 조문을 추정하지 않는다.
4. 가지조문은 `제33조의2`로 표기한다. 사례 검증·로컬 버튼·공개 웹 형식의 사례 버튼을 함께 고쳤다.
5. 소관기관은 문서별로 검사한다. 다른 분야의 허용 기관 합집합을 적용하지 않는다. 보조금의 기획예산처 소관을 재정경제부로 바꾸지 않는다.

## 검증 범위

새 분야 사례 원문을 독립적으로 재확인했고, 인증값 출력 방지·문서별 범위·부재 자료·많은 무관 연결·문맥 후보·위조된 문맥·본문 부재 등의 반례를 검사한다. 작은 자료 묶음과 압축·체크섬·기존 자료 보존·파일/용량 한도를 검사한다. 전체 오프라인 Python 83개 실행 중 의료 증분 빌더의 고정 분야 수 가정 한 건이 실패해 보완하고 재시험했다. Node 12개 실행은 모두 통과했다. 추가 및 영향받은 Python 9개 실행은 최종 모두 통과했다.

이 검증은 분야 전체의 누락률·법적 정확도 보증이 아니다. 별표·서식 내부 문구, 부칙과 지침 내부 문단 참조는 이번 작업에서 분석하지 않는다. 실제 대상 여부와 개정 필요성은 공식 원문과 업무 맥락을 검토해야 한다.
