# 2026-10-26 판본 점검 수동 확인 기록

확인 기준일: 2026-10-26. 공개 기준 자료 버전: `14e03b8d78d2892d185d`.

이번 기록은 공식 API의 고정 식별번호·판본 본문과 발령기관 자료를 대조한 결과다. 시행일이 충돌하거나 메타데이터가 비정상인 자료는 추정으로 새 현행본으로 바꾸지 않는다. 판본 점검은 별표·첨부파일 내용의 변경이나 미수집 법령의 신규 제정까지 확인한 것을 뜻하지 않는다.

## 1. 선불식 할부거래에서의 소비자보호 지침: 교체 보류

- 고유번호: `39435`.
- 기존 수집 판본: `2100000235042`, 제451호, 시행 `2024-01-09`. 공식 API의 현행 여부는 `Y`.
- 새 판본: `2100000287152`, 제502호, 발령 `2026-10-23`. 공식 API는 시행일을 `2026-10-29`, 현행 여부를 `N`으로 제공한다.
- 공정위의 2026-10-23 보도자료는 10월 23일부터 시행한다고 설명한다. 정책브리핑에 전재된 본문뿐 아니라 해당 보도자료의 원첨부 HWPX에서도 같은 날짜를 확인했다.
- 새 판본의 API 부칙 목록은 2024년 제451호까지이고, 제502호의 시행 부칙은 확인되지 않았다. 보도자료 첨부의 신구조문대비표에도 이 충돌을 해소하는 시행 부칙은 없다.

**결정:** 기존 수집본을 보존한다. 새 판본을 10월 23일 시행본으로 임의 보정하거나, 10월 29일 시행 예정이라고 확정하지 않는다. 원 발령문 또는 공식 자료 정정으로 시행일을 확인한 뒤 교체한다. 단순히 현행·예정 판본이 함께 검색되는 현상으로만 설명하지 않고, 출처 간 날짜 불일치를 보류 사유로 기록한다.

## 2. 대전광역시 동구 효행가정 지원 조례: 기존 시행일 유지

- 고유번호: `2051815`, 판본번호: `764640`.
- 제정·공포: `2009-11-30`, 제839호.
- 공식 API의 시행일 필드는 `99991231`이다. 기존 공개 판본과 판본번호는 같다.
- 해당 판본 부칙은 “이 조례는 공포한 날부터 시행한다.”라고 정한다.

**결정:** 이 판본은 공포일과 부칙에 근거하여 기존 표시 시행일 `2009-11-30`을 유지한다. 원시 API 값 `99991231`은 이상 메타데이터로 보존한다. 이를 실제 미래 시행일로 안내하지 않는다. 이 판본에 한정한 판단이며, 다른 법령의 `99991231`을 일괄적으로 공포일로 치환하는 규칙을 만들지 않는다.

## 4. 본문 보존 및 분석 범위 검증

새 판본 25건을 기존 공개 본문과 비교한 결과, 24건은 조문 또는 비정형 본문에 문자의 차이가 있고, 1건은 조문 본문이 같다. 같은 1건은 ‘도심항공교통 활용 촉진 및 지원에 관한 법률’이다. 이 법률은 판본·시행일 정보와 31개 조문의 시행일 메타데이터가 바뀌지만 수집된 조문 문구는 같다. 이 비교는 법적 효과가 같거나 다르다는 판정이 아니다.

- 5개 문서에 조문번호 추가가 있고, 조문번호가 목록에서 빠진 문서는 없다. ‘삭제’ 문구로 남는 조문은 별도로 문구 차이에 포함된다.
- 23개 문서는 기존 조문 문구에 차이가 있다. 감염병 진단기준 고시는 구조화된 조문 대신 비정형 본문에 차이가 있다.
- 국유재산의 선택 분석 대상 2개 법률은 새 본문 전체를 보존한다. 기존 선택 분석 범위 밖 조문의 본문을 제거하지 않고 분석 제한 안내를 유지한다.
- 감염병 신고를 위한 진단기준 고시는 최신 비정형 원문 77,145자를 읽기용으로 보존한다. 조문 연결 분석은 미완료이며, 전체 원문 수집과 조문 분석 완료를 구분한다.
- 새 법령·시행령·시행규칙 9건의 조문별 시행일은 모두 존재하며, 기준일보다 미래인 조문 시행일은 없다.

비교 결과의 세부 해시·조문별 차이는 로컬 작업 산출물 `output/edition-refresh-20261026/body-diff.json`에 기록했다. 검토 시점의 `prepare_fresh` 함수는 25건·26개 분야 적용에서 원문 조문번호·제목·본문·시행일·참고자료와 비정형 본문을 변경하지 않았다. 이 검증은 준비 단계의 원문 보존 검사이며 최종 배포 파일 검증을 대신하지 않는다.
