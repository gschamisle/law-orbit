# 법령 전체 연결 보기 — 2026-10-14

## 변경

- 조문이 분석된 법령을 드롭다운에서 선택하면 첫 조문으로 자동 이동하지 않고 법령 전체 연결을 표시한다.
- 분야 전체 지도, 선택 법령 전체 연결, 조문·항·호·목 연결의 세 수준을 유지한다.
- 전체 지도에 그려진 일부 선이 아닌 해당 분야 `all_links`에서 선택 법령의 인용·역인용을 취한다. 자기 법령 내부 연결과 이웃 법령끼리의 선은 제외한다.
- 지도나 목록에서 연결 법령을 선택하면 그 두 법령 사이의 인용 근거를 펼친다. 기준 법령은 유지하고 연결 조문 본문은 기존 읽기 창으로 연다.
- 조문 연결 자료는 법령 쌍을 펼칠 때 내려받는다. 전 분야 재수집이나 추가 자료 파일 생성은 하지 않는다. 오프라인 화면에 새 모듈을 포함한다.
- 조문이 없는 PDF·문단형 자료는 기존 본문 열람 흐름을 유지한다. 명시적 조문 링크와 실무 사례는 기존처럼 지정 조문으로 열린다.

## 범위

법령 전체 지도는 현재 분야의 수집 법령 집계를 사용한다. 별도 분야 간 연결 자료는 기존 조문 탐색에서 확인한다. 법령 전체·문맥 참조를 포함하므로 법령 수나 인용 근거 수를 개정 의무 수로 해석하지 않는다. 법령 간 연결 존재와 공법상 당사자소송 해당 여부는 별개의 판단이다.
