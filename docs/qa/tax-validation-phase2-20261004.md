# 국세 추가 검증 1–4 — 2026-10-04

추가 표본에서 발견한 잘못된 법령 소속·인용 누락·서식 번호 손실을 보완했다. 기존 기대값에 맞는 행이 있다는 것뿐 아니라, 잘못 붙은 행과 실제 본문 클릭 대상도 점검했다. **이 결과는 국세 전체의 정확도나 법적 적용을 보증하지 않는다.**

문구·대상 범위·발생·실행 명령은 서로 다른 단위다. 이 수치를 하나의 정확도 백분율로 합치지 않는다. 기존 회귀 문구 중 서로 다른 출처 조문 번호의 주변 문맥 2개는 클릭·범위의 구조만 점검했으며 의미상 인용의 정답을 새로 판정하지 않았다.

## 1. 잘못 붙은 연결과 실제 본문 클릭

- 출처 법령·조문·판본과 원문 span, 실제 raw 일치, 대상 ID와 카탈로그, 클릭하는 neighbor 번호를 함께 확인한다.
- 기대 범위를 넘는 대상, 잘린 항호목, 중복 발생, 표시 번호와 실제 열리는 본문의 불일치를 실패로 처리한다.
- 한 범위 안의 현재 읽는 자기 조문은 별도 이웃 카드가 없다. 같은 법의 현재 본문이 열려 있고 자기참조 건수와 원문 전체 범위가 확인되는 때에만 이 조문의 추가 클릭을 면제한다. 나머지 범위 조문은 모두 실제 연결이 있어야 한다.
- 검사기는 운영 인용 파서·scope 함수를 호출하지 않는다. 변형 시험으로 잘못된 ID·클릭·범위·원문·중복을 넣어 실패하는지도 확인했다.

## 2. 공식 원문과 네 가지 예외

1. **소득세법 제14조 → 제21조제1항제27호:** 동판 공식 원문에도 있는 인용이다. 공식 참고자료의 부분 시행일 `2027.1.1`을 복원해 표시한다. 현재 수집 본문에 없는 제27호를 다른 번호로 바꾸거나 새로 만들어 넣지 않았다.
2. **법인세법 제24조 표:** 줄바꿈된 `사회적기업 육성법 제2조제1호`의 법령명 소속을 복원했다. 원문과 위치는 유지한다.
3. **조세특례제한법 시행령 제79조의4·제79조의5:** 같은 MST·시행일의 공식 XML/PDF/GIF 대조로 잘못 저장된 `- `를 `×`로 바로잡았다. 두 문자 위치와 전문 전후 해시가 일치하는 경우만 수정한다.
4. 참고자료는 별도 metadata로 보관한다. 조문 본문에 합치거나 참고자료의 번호에서 새 인용을 만들지 않는다.

[정확한 보정 계획과 공식 XML 해시](tax-source-repairs-20261004.json). 법인세법 시행규칙 제49조의 비표준 `영 제95조1항`도 MST287787의 공식 XML에서 재확인했다. 원문은 보존하고 구조화 범위에만 빠진 `제`를 보충한다.

## 3. 새 표본과 보완

[선정·원문 주석·한계](tax-blind-audit-20261004.md) · [고정 기대값](tax-blind-samples-20261004.json).

원문을 먼저 읽어 기대값을 고정한 뒤 앱 결과를 열었다. 같은 AI 작업이 기존 파서 구조를 알고 있었으므로 독립 인간 전문가의 맹검이나 무작위 표본이라고 부르지 않는다. 대부분의 24조는 저장된 공식 API 수집 본문을 기준으로 하며, 신규 공식 XML 전문 일치를 모두 재확인한 것은 아니다.

- 구법 판본 괄호 뒤 법령 소속, 같은 항·동항, 괄호 속 법명과 밖의 소속 경계, 표 번호가 끼어 있는 조문 열거를 보완했다.
- `이 조부터 …까지`의 범위를 유지해 중간 조문이 빠지지 않게 했다.
- 표에 여러 줄로 끊긴 법인세법 시행규칙 제49조의 국세기본법 제47조의2~제47조의5 인용은 **판본·전문 해시·정확한 span으로 고정한 선정 사례만** 복원한다. 표 전체를 해석했다고 보지 않는다.
- 서식의 `제7호의2`와 카탈로그 `제7의2호`를 같은 가지번호로 연결하되 원문·표시 번호는 보존한다.
- 부가가치세법 시행규칙의 별지16(1)·(2)는 같은 [공식 PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=162619767)의 1쪽·3쪽에서 직접 확인했다. 번호와 페이지를 표시하고 같은 파일을 연다. PDF SHA-256: `bd850a4cd5318d5eb7e185433868ecfa8a52d1ec512f53d52090c7c9ecf63d72`. 다른 서식의 세부번호에 이 묶음을 일반화하지 않는다.
- 번호 없는 `법에 의한 신고`, `법 또는 다른 법률` 두 표현만 모법 참조로 추가한다. 불특정 다른 법률을 추측하지 않는다.
- 구명칭 외감법의 법령 단위 참조만 현 정식 명칭으로 연결한다. [법률 제15022호 개정문](https://www.law.go.kr/LSW/lsSideInfoP.do?ancNo=15022&ancYd=20171031&chrClsCd=010202&lsNm=주식회사의+외부감사에+관한+법률&urlMode=lsRvsDocInfoR)이 제명 변경을 명시한다. 원문 명칭은 보존하며 옛 조문 번호의 동일성은 추정하지 않는다.

**미검증 범위:** 표 내부 호·행 위치의 본문 강조는 12문구에서 기본 조·항만 확인했다. 명시된 개정 전 판본 2문구는 현재 같은 번호로 읽을 수 있어도 과거 판본 일치가 미검증이다. 카드와 본문 읽기 창에 이를 표시한다.

## 4. 원문에서 시작한 역인용

[고정 원문 기대값](tax-reverse-source-samples-20261004.json). 대상은 법인세법76의18, 국세기본법81의13, 조세특례제한법126의2, 상속세및증여세법45의2, 법인세법시행령89, 소득세법시행령155다. 먼저 저장 원문에서 직접 번호·범위를 찾아 144문단을 읽고 115개 긍정 문단과 29개 음성 문단으로 분류했다. 115문단에 기대 발생 130개가 있다.

명시 법령명 또는 같은 법령군으로 한정한 탐색이므로, 다른 법령군의 미명시 별칭·의미상 연결까지 전수 누락을 찾았다는 주장은 하지 않는다. 소득세법 시행령156의2·156의3에서 빠진 같은 항/동항 제2호가 이 절차로 발견되어 보완됐다.
