# 인용 문맥 보완과 전 분야 판본 점검 — 2026-10-13

## 바뀐 동작

괄호 안의 다른 법령 설명, 쉼표 뒤의 정의 문장, 실제 조문 열거를 구분하도록 엄격 인용 분석 경로를 보완했다. 예를 들어 지방세기본법 제93조의2의 `…외국법인을 말하며, 제153조에 따라…`에서 제153조를 법인세법으로 잘못 이어 붙이던 것을 지방세기본법으로 바로잡았다. 괄호 안에 다른 법령이 등장해도 괄호 밖의 원래 열거가 이어지는 경우에는 원래 법령 소속을 유지한다.

명시적인 `같은 법`은 별도 문맥 후보로 보존한다. 미수집 대상이나 문맥상 불확실한 연결을 확정 연결로 승격하지 않는다. 범위 인용 하나에서 여러 대상 조문이 나올 수 있으므로 아래 건수는 법령 수나 개정 필요 건수가 아니다.
