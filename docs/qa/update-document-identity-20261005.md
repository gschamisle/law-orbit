# 명칭 변경에 따른 법령 자료 갱신 — 2026-10-05

## 문제와 변경

금융 자료의 공식 문서 ID가 그대로인데 이름이 바뀌면 기존 갱신기는 누락으로 판단했다. 수집 범위·시행일 후퇴·기존 본문 손실을 모두 안정적인 문서 ID로 비교하도록 보완했다.

- 금융: `provider:document_id`와 UID가 정확히 일치하는지 확인한다. 법률·시행령의 `law_id`도 확인한다.
- 국세: `law_id`로 문서 동일성을 비교한다. 검색 목록의 수집 범위 검사에도 같은 기준을 적용한다.
- 기존/새 자료의 빈 ID·중복 ID·중복 이름, 같은 이름의 다른 문서 ID를 허용하지 않는다.
- 문서 이름만 바뀌어도 시행일 후퇴·미래 판본·빈 본문·원문 인용 근거 불일치를 계속 차단한다.
- 본문이나 인용 문구를 새 이름으로 치환하지 않는다. 새 원문으로 그래프를 재생성한다.
- 성공 보고에 이전 이름·새 이름·문서 ID를 기록한다. 검증 → 이전본 백업 → 원자적 교체 순서와 잠금 처리를 유지한다.

자동 갱신이 실행되는 `FscLawGalaxy-Stage2`와 공개 코드 작업 폴더 `LawGalaxy-StateProperty`에 같은 보완을 반영했다. 두 폴더의 기존 국세 빌더 진입점 차이는 유지했다.
