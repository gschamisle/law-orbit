# 외환·금융 사이의 조문 연결

외환 업무에서 은행·증권 규정을 함께 읽을 수 있도록 정적 웹 앱에 분야 간 연결을 추가했습니다. 외환과 금융의 메뉴, 법령 목록, 전체 지도, 검색·선택 상태는 각각 유지합니다.

## 화면에서 사용하는 방법

1. 외환에서 법령과 조문을 선택합니다. `금융 연결 포함`을 켜면 해당 조문과 직접 연결된 금융 조문을 함께 표시합니다.
2. 금융 쪽 조문에는 **분야 밖 관련 조문 · 금융 / 은행** 또는 **증권·자산운용** 등의 태그를 붙입니다. 금융에서는 `외환 연결 포함`으로 역방향 탐색도 가능합니다.
3. 연결된 점이나 `본문 보기`를 누르면 현재 검토 기준을 유지한 채 연결 조문의 수집 본문이 열립니다. `이 조문을 중심으로 탐색`을 눌러야 탐색 기준과 분야가 바뀝니다.
4. 범위·항·호 인용은 기존 공통 분석 엔진과 필터를 사용합니다. 법령 전체를 참조한 역인용은 기존 `법령 전체 참조`를 켜야 나옵니다.

예를 들어 **외국환거래규정 제7-36조 → 금융투자업규정 제5-1조제6호**의 인용과 본문을 확인할 수 있습니다. 금융투자업규정 제5-1조에서 외국환거래규정 제7-36조의 역인용도 찾습니다.

## 자료와 판본

연결 자료는 별도의 두 압축 파일과 `manifest.cross_domain`에 보관합니다. 기존 분야별 원문·분석 파일, `manifest.domains`는 변경하지 않습니다. 브라우저는 두 분야의 수집 판본이 일치하는 연결 자료만 사용하며, 대상 본문도 문서 ID와 시행일을 대조합니다.

2026-09-22 로컬 검증은 공개 웹용으로 만들어 둔 외환 **2026-09-21**, 금융 **2026-09-17** 수집 자료를 사용했습니다. 이번 작업에서 API 재수집은 하지 않았습니다. 두 분야의 날짜를 화면에 표시하며 같은 기준일의 전 법령을 재수집했다는 뜻은 아닙니다.

| 확인 항목 | 건수 |
|---|---:|
| 조문을 특정한 분야 간 인용 | 183 |
| 법령 전체 참조 | 126 |
| 별표를 특정한 인용 | 7 |
| 합계 | 316 |
| 기존 이름 해석 실패에서 복구한 인용 | 15 |

15건은 위 합계에 포함됩니다. 건수는 원문 인용 위치·대상별 근거 수이며, 법령 수·개정 의무 수·서로 다른 연결선 수가 아닙니다. 추가 연결 파일은 약 145KB입니다.

대상을 확인하지 못한 `금융회사등의 해외진출에 관한 규정 → 외국환거래규정 제8-2조` 1건은 미해결로 남겼습니다. 비슷한 번호로 대체하지 않았습니다.

## 한계

- 명시적인 법령·규정명과 인용 문구가 있는 관계를 다룹니다. 문구만 비슷하거나 업무상 관련된 관계를 자동으로 확정하지 않습니다.
- `외국환거래규정 제2-11조의2 → 은행업감독업무시행세칙 별표 4-1`처럼 별표를 지목한 사실은 표시하지만, 별표 본문과 표 내부 인용은 **미분석**입니다. 공식 법령·규정 페이지에서 별표를 확인하도록 안내합니다.
- 미수집·삭제 조문, 문맥 확인 후보를 구분합니다. 인용 연결만으로 연계개정 필요 여부를 확정하지 않습니다.
- 기존 Streamlit 화면은 이번 변경 대상이 아닙니다. 정적 웹 앱의 외환·금융 조문 탐색에 적용합니다.
- 연결 자료를 저장해도 모든 상대 분야 본문이 자동 저장되는 것은 아닙니다. 오프라인에서는 미리 열람·저장한 본문만 볼 수 있습니다.

## 빌드

전체 정적 사이트를 만드는 `scripts.build_static_galaxies`는 마지막에 외환·금융 연결을 자동 생성합니다. 기존 정적 자료를 유지하면서 새 미리보기를 만들려면 다음 명령을 사용합니다.

```powershell
uv run python -m scripts.build_forex_finance_site --base-site output/static-mofe-reviewed --destination output/static-forex-finance-preview
uv run python -m http.server 8521 --bind 127.0.0.1 --directory output/static-forex-finance-preview
```

대상 폴더가 있으면 중단합니다. 현재 검증한 폴더는 `output/static-forex-finance-preview-v2`입니다. 새 갱신 자료에는 이전 연결 파일을 재사용하지 말고, 두 분야의 새 본문과 분석 결과로 다시 빌드해야 합니다.

## 검증

- 기존 국세·금융·외환 테스트 및 신규 테스트 총 69개 통과. 새 빌드 연결 테스트는 68개 회귀 실행 후 추가해 별도로 실행했습니다.
- 브라우저 연결·본문 선택 로직 검증 통과.
- 기존 압축 자료 19,545개를 원본과 해시 대조, 변경 없음. 전체 정적 사이트 검증 통과.
- 실화면에서 외환 제7-36조의 금융 본문 열람, 중심 유지, 명시적 분야 이동, 금융의 역인용, 연결 켜기·끄기, 국세에서 연결 제어 숨김, 외환 선택 상태 복원, 은행 별표의 미분석 표시를 확인했습니다.
- 실제 휴대전화 터치와 네트워크를 끊은 재접속은 미실행입니다.

검증 결과는 `output/forex-finance-tests/verification.json`, 회귀 실행 기록은 같은 폴더의 `regression.log`에 있습니다. 이 변경의 커밋·푸시·공개 배포는 아직 하지 않았습니다.
