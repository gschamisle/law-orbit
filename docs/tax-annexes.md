# 국세 별표 3개 본문·인용 분석

수집 기준 자료: 2026-09-28 국세 자료 묶음. 원본 파일 확인·분석·시각 점검: 2026-09-29.

총 237개 원문 문단, HWP 내부 셀 113개이다. HWP의 문서 배치용 셀에는 제목과 비고도 포함되므로 화면에 보이는 표 칸 수와 같지 않다. 한 셀의 여러 문단은 원래 문단 경계와 셀 주소를 함께 보존한다.

인용 근거는 수집된 조문으로 연결하는 7건과 미수집 법령으로 가는 27건이다. 34건은 인용 위치와 대상 범위를 조합한 근거 수이며, 서로 다른 법령 수나 개정 필요 건수가 아니다. 한 문구가 두 목을 열거하면 두 대상 근거가 된다. 별표 제목의 ‘제15조제3항 관련’ 같은 연결은 기존 제목 연결에 남고 별표 본문 인용 수에는 포함되지 않는다.

법인세법 시행규칙 별표 6의 `zero-explicit-citations`는 **본문 분석 완료, 본문에서 다른 법령·조문의 명시적 인용 0건**을 뜻한다. 표의 업종 코드·내용연수·비고를 모두 읽을 수 있다. ‘제4호’, ‘제9호’, 다른 별표 등 내부 참조의 자동 연결 완료를 뜻하지 않는다.

조세특례제한법 시행령 별표 7·7의2는 이번 선정 범위에 포함하지 않았다.

## 원본과 판본 보호

- `data/tax-annex-sources.json`에 소유 법령 ID·일련번호·시행일·수집 XML 해시, 별표 표제·API 본문 해시, 공식 HWP/PDF 파일 URL·크기·SHA-256·시그니처를 고정했다.
- HWP/PDF 여섯 원본과 분석 JSON 세 개의 해시를 연결 시 다시 확인한다. 분석 JSON 자체의 해시도 고정하므로 본문과 내부 해시를 함께 바꾸어도 받아들이지 않는다.
- 원본 다운로드는 공개된 `www.law.go.kr/LSW/flDownload.do?flSeq=...`만 허용한다. API 인증키를 사용하거나 저장하지 않는다. 다른 판본·다른 파일이 오면 기존 결과에 덮어쓰지 않고 중단한다.
- 소유 법령 시행일과 별표의 마지막 개정 표시는 구분한다. PDF에 표시된 별표 개정일은 법인세규칙 별표 5가 2024-11-11, 별표 6이 2024-03-22, 조특령 별표 6이 2026-02-27이다.

공식 법령 판본: [법인세법 시행규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=287787&efYd=20260701), [조세특례제한법 시행령](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=288915&efYd=20260918).

## 구조와 인용 경계

공통 `core/annex_analysis.py`의 검증 함수·인용 수집기를 재사용한다. 기존 공통 HWP 추출기는 검증하지 않은 다중 셀 표를 거부한다. 국세의 이 세 파일만 별도 제한된 추출기로 처리한다.

HWP 5.0.1.1의 단일 본문 섹션·최상위 표·47바이트 셀 목록 레코드만 받는다. 행·열 주소, 병합 범위, 셀 문단 수, 각 레코드 위치를 보존한다. 셀 겹침, 빈 격자, 잘린 레코드, 중첩·복수 표, 지원하지 않는 셀 내부 컨트롤은 실패 처리한다. 셀·문단을 순서대로 합친 내용과 공통 HWP 전체 텍스트 추출 결과가 공백을 제외하고 완전히 같아야 한다. API 표에서 유실되던 표 밖 비고도 HWP의 배치 셀 안에 있으므로 함께 보존된다.

구조 근거는 [한컴 HWP 5.0 공개 명세](https://cdn.hancom.com/link/docs/한글문서파일형식_5.0_revision1.2.pdf)의 레코드·표·셀 설명이다. 현행 파일의 셀 목록 앞 8바이트에는 예약된 2바이트가 있으며, [pyhwp의 원천 모델 정의](https://github.com/mete0r/pyhwp/blob/master/src/hwp5/binmodel/tagid56_list_header.py)와 실제 셀 격자·문단 수를 대조했다. 외부 파서의 코드를 복사하거나 의존성을 추가하지 않았다.

각 셀·문단은 독립적으로 인용을 분석한다. 옆 셀·앞 문단의 법령명이나 별칭을 가져오지 않는다. 법령명이 없는 ‘제N조’는 자동으로 소유 법령에 귀속하지 않는다. 예외는 PDF 1쪽 1.가.4)의 ‘제25조의3제3항제2호가목’ 한 곳뿐이며, 문단 전체 해시·인용 문자열·대상 범위를 출처 목록에 고정했다. 같은 시행령 제25조의3제3항제2호가목의 연구ㆍ시험용 시설 정의를 실제 수집 본문과 대조했다. 이 허용 근거는 다른 문단이나 판본에 재사용되지 않는다.

그 밖의 수집 조문 연결 6건은 같은 문단의 명시된 법령명 5건과 상위법을 뜻하는 ‘법’ 1건이다. ‘같은 법’은 같은 문단에서 확인된 법령명만 사용한다. ‘같은 조 제3항’처럼 상대 조문이나 표 내부의 ‘제4호’ 같은 참조 25건은 원문 확인 항목으로 남긴다.

## 원본 시각 점검

공식 PDF 12쪽 전체를 렌더링해서 확인했다. 법인세규칙 별표 5는 표 1쪽과 이어지는 비고 2쪽, 별표 6은 병합 칸이 이어지는 6쪽 전체, 조특령 별표 6은 연구개발·인력개발 항목 4쪽 전체이다.

- 법인세규칙 별표 5: 본표 4개 구분과 비고 1·2·3, 3.가·나·다 보존. 두 쪽에 걸친 법령명이 HWP의 원래 문단 안에서 온전히 보존됨을 확인.
- 법인세규칙 별표 6: 9개 구분, 2번의 긴 병합 칸, 쪽을 넘어 이어지는 업종 설명, 마지막 비고 2개 보존. 병합 셀의 수치·조건을 다른 셀에 재배분하지 않음.
- 조특령 별표 6: 1. 연구개발과 2. 인력개발의 실제 번호 계층, 위탁·공동연구 문단의 쪽 이어짐, 마지막 2.차 항목까지 확인. 인용 34건의 위치·문자열과 수집 조문 연결 7건의 대상 법령을 대조.

시각 점검은 공식 PDF의 배치·문구와 추출 본문의 대조이며, 감가상각·세액공제 계산이나 적용 판정이 아니다. UI는 원래 표 배치를 복제하지 않고 셀·문단 순서로 읽게 하며 공식 원본 링크를 함께 제공한다.

## 재현과 연결

정상 Python 환경에서:

```text
python -m scripts.collect_tax_annexes
python -m unittest scripts.test_tax_annex
```

원본이 없는 새 폴더에서는 `--collect --output 새폴더`를 지정한다. 기본 입력은 형제 저장소 `FscLawGalaxy-Stage2/output/tax-universe/bundle.json`의 해시로 고정한 2026-09-28 자료이며 읽기만 한다. 다른 경로의 동일 파일은 `--source-bundle`로 지정할 수 있다. 파일이 같은지 먼저 확인하고, 최종 결과가 기존 파일과 다르면 덮어쓰지 않는다.

국세 정적 빌드 연결:

```python
from core.tax_annex import attach, merge_graph
from core.universe_builder import build_tax_universe

source = attach(source)
graph = merge_graph(build_tax_universe(source), source)
```

`attach`는 입력을 복사하고 지정한 세 개에만 `body_analysis`를 넣는다. `merge_graph`는 국세 별표 전용 인용 경계 검사를 적용한 뒤 별표 본문 근거를 더한다. `build_tax_universe(..., annex_bodies=True)`를 직접 사용하는 경로는 이 국세 전용 검사를 거치지 않으므로 이 선정 자료의 공개 빌드에는 사용하지 않는다.

결과 폴더 `output/tax-annexes-20260929/`의 최종 파일:

- `source-manifest.json`: 최종 출처·분석 해시와 검증한 자기 조문 인용.
- `*-analysis.json`, `*-body.txt`, `*-api-source.txt`: 본문 구조·읽기용 텍스트·수집 API 본문.
- `citations.json`, `verification.json`, `pdf-visual-review.json`: 인용·범위·검증 기록.
- `*.hwp`, `*.pdf`, `source-review/*.png`: 보존 공식 원본과 시각 확인용 렌더링.

`*-initial-analysis.json`, `*-api.txt`, `*-hwp.txt`, `sources.json`은 비교를 위해 남긴 초기 추출 기록이며 연결·공개 빌드는 읽지 않는다. 기존 공개 정적 폴더와 원래 국세 자료 묶음은 변경하지 않는다.

검증 결과: 12개 회귀 테스트 통과. 원본·분석 파일 변조/누락, 판본 변경, 셀 중복/누락, 문단을 넘는 법령 귀속, 인용 0건 상태, 비고 보존, 인용 위치, 입력 불변, 재실행의 동일 결과를 확인했다. 세 별표 밖의 전수 정확도·내부 참조 해석·수치 및 세액 계산·개별 적용 요건은 검증 범위 밖이다.
