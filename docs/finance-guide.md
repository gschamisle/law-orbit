# 금융 업무·제도 길잡이

첫 주제는 금융상품 판매·소비자보호다. 기존 금융 본문과 인용 자료를 재사용하되, 편집한 업무 안내와 자동 추출 인용을 구별한다.

## 범위와 읽는 방법

- 업무 흐름: 상품·역할 → 인가·등록 → 권유·설명·광고 → 거래·중개 원칙 → 권리·분쟁 해결. 화살표는 읽는 순서이며 법적 필수 절차나 인용 관계가 아니다.
- 관리·감독·검사는 영업 전반에 걸쳐 함께 보는 가지다. 분쟁 해결 뒤에만 진행하는 단계로 표시하지 않는다.
- 규율 체계: 대상·업권, 영업 진입, 판매행위, 소비자 권리·구제, 사업자 관리·공적 감독의 다섯 묶음이다. 법적 서열이나 법률 전체의 배타적 분류를 뜻하지 않는다.
- 법률 제17조~제22조의 주요 판매규제는 권유·설명·광고와 거래·중개 원칙에 나누어 연결한다. 화면의 상자 경계가 조문의 적용 시기를 제한하지 않는다.
- 청약철회·위법계약 해지·분쟁조정은 서로 대체되거나 반드시 순서대로 거치는 절차로 설명하지 않는다.
- 모든 상품·업권의 완결된 준법 체크리스트가 아니다. 구체 상품, 소비자 구분, 업무 방식, 예외, 시행령과 감독규정의 세부 요건을 따로 확인해야 한다. 해당 업무의 적법성·권리 성립·제재 가능성을 자동 판정하지 않는다.
- 지배구조·내부통제 전반과 신용정보·금융데이터의 독립 주제는 후속 범위다. 이 첫 주제의 관리책임 노드는 금소법 제16조에 한정한다.

## 판본이 바뀌었을 때

제목·원문 발췌가 계속 일치하더라도 확인 시행일과 달라지면 재확인이 필요하다. 새 판본을 읽고 예외·적용 범위·관련 하위 규정을 확인한 뒤에 설명, 발췌, 시행일, MST, 검토일을 함께 갱신한다. 미수집·제목 불일치·발췌 불일치를 연결 확인으로 표시하지 않는다.

앱의 기존 조문 본문과 공식 출처를 열 수 있게 하며, 업권 필터 때문에 공통법의 근거 버튼이 사라지지 않아야 한다. 이 기능은 금융 첫 주제의 안내를 추가하며 기존 인용 자료를 재분류하거나 변경하지 않는다.

## 화면과 검증

금융 화면의 `업무·제도 길잡이`와 `법령·인용 탐색`으로 진입 방법을 구분한다. 특정 법령·조문을 전달하는 기존 탐색은 길잡이를 거치지 않고 본문과 인용 지도를 연다. 모바일에서는 단계를 선택하면 확인 사항으로 이동하며 `다른 단계 보기`로 돌아올 수 있다.

- `node --test scripts/test_finance_guide.mjs`: 해석한 조문 번호, 정식 법령명·판본·제목·발췌 대조, 요청 실패·선택 변경, 읽기/탐색 분리를 검사한다.
- `node scripts/verify_finance_guide.mjs --site <배포 자료 폴더>`: 실제 배포 본문에 21개 근거가 있는지 검사한다.
- PC 1440px, 모바일 390px·320px에서 전환·본문 열기·인용 지도 이동·가로 넘침을 확인했다. iOS 실기기 확인을 대신하지 않는다.

배포 시에는 현재 소스로 브라우저 셸을 다시 만들고 고정 공개 자료 묶음과 `static-web-release.json`도 함께 갱신해야 한다. 기존 자료 묶음에 새 셸이 없는 상태에서 코드만 푸시하면 셸 일치 검사에서 실패한다. 이번 배포 묶음은 `static-web-2026-10-27-finance-guide`이며 법령 자료 버전은 그대로 유지한다.
