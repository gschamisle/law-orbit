# 헌법 — 원칙과 제도의 출발점

2026-09-28 공개 베타에 추가한 범위입니다.

## 메뉴와 연결 원칙

메뉴 최상단에 독립된 헌법 항목을 두고, 구분선 아래에 기존 분야별 법령을 배치합니다. 첫 방문은 헌법에서 시작하고 재방문 시 마지막 분야를 유지합니다. 각 업무 분야는 바로 열 수 있으며, 헌법과 별개의 수집 자료·선택 상태를 사용합니다. 공통 수집·인용·읽기·시각화 엔진을 재사용합니다.

1. **명시적 인용:** 원문에 있는 헌법 조문 인용은 기존 인용선과 근거 목록에서 확인합니다. 헌법 전체를 언급한 인용에는 임의의 조문 번호를 붙이지 않습니다.
2. **관련 법률 안내:** 기본권·국가기관·경제질서를 구체화하는 법률 11개를 편집한 길잡이로 제공합니다. 직접 인용과 구분하고 인용선·인용 건수에 넣지 않습니다. 양쪽 원문의 조문·판본·해시와 공식 출처를 저장해 검증합니다.

예를 들어 헌법 제32조 → 근로기준법 제1조는 관련 법률 안내입니다. 근로기준법 제1조가 헌법을 언급하지만 제32조를 번호로 인용한 것은 아닙니다. 반면 국회법 제98조제3항의 `헌법 제53조제6항`은 실제 조문 인용으로 표시합니다.

## 수집 범위

헌법과 선정한 법률 14개만 포함합니다. 헌법 관련 법령 전체나 전국 역인용의 전수 수집 결과가 아닙니다.

- 대한민국헌법
- 국회법, 정부조직법, 법원조직법, 헌법재판소법, 지방자치법
- 공직선거법, 국민투표법
- 국세기본법, 근로기준법, 노동조합 및 노동관계조정법
- 교육기본법, 사회보장기본법, 환경정책기본법
- 독점규제 및 공정거래에 관한 법률

법제처 API의 현행 목록과 본문에서 이름·ID·시행일·소관을 대조했습니다. 헌법은 API의 소관부처 빈 값과 법종 `헌법`을 확인했고, 국회법은 목록의 `국회`와 본문의 `국회사무처` 차이를 해당 법률 ID에 한해 검증해 처리합니다. 다른 법률의 소관 검사를 완화하지 않았습니다.

| 항목 | 건수 |
|---|---:|
| 수집 문서 | 15 |
| 헌법 본칙 조문 | 130 |
| 전체 수집 조문 | 2,003 |
| 헌법을 인용하는 수집 법률 | 7 |
| 번호를 명시한 헌법 인용 근거 | 16 |
| 헌법 전체를 참조하는 근거 | 22 |
| 편집한 관련 법률 안내 | 11 |
| 전체 내부 인용 근거 레코드 | 2,650 |
| 미수집 외부 인용 근거 | 1,103 |
| 해석·연결 확인 필요 | 169 |

전체 내부 인용에는 각 법률 내부 인용도 포함됩니다. 근거 레코드 수는 개정 필요 건수나 서로 다른 연결 조문 수와 다릅니다.

시작 사례는 헌법 제53조(국회법), 제72조·제130조(국민투표법)의 실제 역인용입니다. 법률의 공포와 국민투표의 후속 절차를 읽을 수 있습니다. 위헌성·헌법상 의무 이행을 판단하지 않습니다. 판례·헌법재판소 결정례·학설·부칙·별표 본문은 이 자료에서 미분석입니다.

## 실행

프로젝트 Python 환경과 기존 로컬 API 인증 설정을 사용합니다. 인증값은 명령 인자·로그·Git에 넣지 않습니다.

```powershell
python -m scripts.collect_constitution_universe --stage inventory
python -m scripts.collect_constitution_universe --stage bodies
python -m scripts.collect_constitution_universe --stage build
python -m unittest scripts.test_constitution

# 기존 출력은 보존하고 새 폴더에만 생성합니다.
python -m scripts.build_labor_site --domain constitution --base-site output/static-labor-preview-20260928 --destination output/static-foundations-preview-new
python -m http.server 8543 --bind 127.0.0.1 --directory output/static-foundations-preview-new
```

수집 출력은 `output/constitution-universe/`입니다. 데이터가 없을 때 다른 분야의 그래프로 대체하지 않습니다. 기존 MOFE 일괄 수집 대상과 주간 자동 갱신 예약은 바꾸지 않았습니다.

## 검증

- 헌법·고용노동·조달·기존 분야·앱 메뉴 관련 Python 검사 58개 통과. 앞선 노동·별표·범위 인용·시각화 검사 56개 및 JavaScript 검사 19개도 통과했습니다. 검사 묶음에는 중복 항목이 있으므로 합산하지 않습니다.
- 실제 수집 원문과 조문 번호·근거 위치·판본을 대조했고, 관련 법률 안내가 실제 인용 그래프에 삽입되지 않는지 검사했습니다.
- 합친 정적 미리보기는 5,614개 파일, 약 181 MB입니다. 자료 경로·해시·파일 수·도메인 검사를 통과했습니다.
- 고용노동 미리보기를 기준으로 기존 13개 분야의 카탈로그와 논리 자료 20,050개의 바이트가 유지됐습니다. 헌법 추가분은 54개 파일, 약 1.4 MB입니다.
- 브라우저에서 관련 법률 본문 열기, 실제 역인용과 인용 문구 강조, 분야별 선택 유지, 모바일 폭을 확인했습니다.
- 저장소 전체 테스트, 공개 서버 반영 검증, 주간 자동 갱신은 미실행입니다.
