# 지방세 은하 구현·검증 결과

검증일: 2026-09-17. 공개 자료 버전: `20260917-112417`.

## 결과

기존 법령은하 메뉴에 독립 **지방세** 탭을 추가했다. 중앙 법령을 검색하면 직접 인용·역인용과 전국의 조례 인용 지역을 확인하고, 한 지역의 조례·규칙만 지도에 펼칠 수 있다. 수집 본문 검색, 시행일·공식 판본 링크, 인용 근거 및 HTML 내려받기를 지원한다.

예시: **지방세법 제4조(부동산 등의 시가표준액)** → 이번에 수집·분석한 범위에서 **239개 지역, 서로 다른 조례·규칙 조문 324개, 인용 근거 326건**. 법령 전체에 대한 참조와 문구 유사성은 이 집계에서 제외했다. 직접 인용을 확인했다는 뜻이며 연계개정 의무의 확정은 아니다.

전국 목록을 받은 것과 전국의 지방세 관련 조례를 의미상 빠짐없이 식별한 것은 다르다. 본문 검색 후보와 제목 보완 범위만 본문을 수집했다. 목록 161,268건 전부의 본문을 분석한 것은 아니다.

### 실제 API에서 확인한 문제

- 동일 자료 1건이 전체 목록과 독립 명칭 검색에서 두 번 반환됐다. 같은 판본·같은 내용임을 확인한 근거를 장부에 기록했다.
- 본문 검색에는 현행 옵션을 주어도 과거 판본과 현행 여부 미확인 결과가 포함됐다. 검색 결과를 그대로 분석 판본으로 사용하지 않았다.
- 분석 보류 53건: 조문 번호 중복 36건, 구조화된 조문 없음 9건, 번호·본문 불일치 4건, 빈 조문 2건, 개정 지시문 혼입 2건. 임의 수정·강제 병합하지 않았다. 원문과 공식 링크는 보존했다.

## 검증

- 전체 오프라인 테스트 **38개 모듈 통과**. 새 지방세 수집·분석·화면 테스트 18개 포함.
- 공통 은하의 터치·확대·소리 테스트 **19개 통과**.
- 실제 수집 데이터로 세법/금융법/지방세의 검색·필터 상태 분리, 사이드바 왕복, 개정안 업로드 위젯 유지 확인. 화면 예외 0건.
- 실제 브라우저에서 지방세 탭 → 지방세법 제4조 → 전국 역인용 → 인천광역시 영종구 펼치기 확인. 중앙 조문 선택이 유지되고 선택 지역의 연결이 추가됐다.
- 강릉시 시세 감면 조례의 ‘법 제177조’가 지방세특례제한법 제177조로 연결되는 실제 사례와 원문 인용 위치를 확인했다.
- 공개 전에 모든 지역 자료의 출처·대상 수록 범위, 본문/그래프 기준일, 인용 문구와 원문 위치의 일치를 검사했다.
- 기존 `data/`와 세법·금융법 공개 자료 **13개 파일의 SHA-256 해시 동일**. 보호 대상 `TaxLawAmend-Impact`의 Git 상태도 깨끗하게 유지됐다.
- 새 수집 산출물 22,681개 파일을 검사한 시점의 인증값 검출 **0건**. API가 반환하는 링크의 인증 항목은 저장 전에 제거한다.
- Git 커밋·푸시 미실행.

## 미구현·미실행

- 지자체 공보와의 전국 전수 대조, API에 없는 자료 보완, 전국 관련 조례의 의미상 무누락 검증: **미실행**.
- 부칙은 저장만 했고, 별표·별지 파일 본문 및 문구 유사성·묵시적 적용 관계: **미분석**.
- 해석 확인 후보의 법적 의미에 대한 사람의 전수 검토: **미실행**.
- 실제 휴대전화 하드웨어 테스트: **미실행**. 공통 터치 동작은 자동 테스트로 검증했다.
- 지방세 자료의 기존 주간/일일 예약 갱신 편입: **미구현**. 기존 세법·금융법 예약은 변경하지 않았다.
