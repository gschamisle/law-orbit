# 별표·서식 번호 연결과 원본 확인

## 범위

조문에 명시된 별표·별지서식 번호를 찾고 해당 공식 첨부파일로 이동하는 기능이다. 별표 내부의 문구·표·수치를 새로 추출하거나 해석하지 않는다. 국세의 선정 별표 3개, 보건·의료의 선정 별표 4개 및 기존 조달 PDF·국유재산 특례 목록 분석은 그대로 유지한다. 내부 본문 분석의 확대는 분야별 후속 작업으로 둔다.

- 번호가 붙은 별표·별지서식을 별도 인용 대상으로 보존한다.
- 명시된 법령명과 확인된 별칭을 사용한다. 소속이 불명확하거나 범위 전체를 확정할 수 없는 문구는 확인 항목으로 남긴다.
- 별표 제목의 ‘제○조 관련’에서 생성된 연결에는 **별표 제목의 관련 조문**을 표시한다. 별표 내부 문구 분석을 뜻하지 않는다.
- 연결 카드의 **별표 원본 1/2**는 수집 당시 공식 파일 주소이다. 주소만 보고 HWP/PDF 형식을 추정하지 않는다.
- 첨부파일 주소가 없으면 **첨부파일 주소 미확보**와 소유 법령 페이지를 안내한다. 없는 본문을 조문 전체로 대체하지 않는다.
- 기존에 본문을 검증한 별표는 **검증된 별표 본문 보기**를 함께 제공한다.

## 누락 보완

공통 별표 추출을 건너뛰던 행정규칙·업무 분야의 별도 조문 분석 경로에 번호 참조를 추가했다. 국세의 기존 추출 경로와 지방조례의 전용 번호 참조 경로는 변경하지 않는다. 명시적 번호 인용과 별표 제목 관계를 합쳐 하나의 확정 인용처럼 표시하지 않는다.

확인 사례는 근로기준법 시행령 제7조의 별표 1, 국민건강보험 요양급여의 기준에 관한 규칙 제15조의 별표 2, 은행업감독업무시행세칙 제4조의 별표 1이다. 이미 번호 연결이 있던 은행법 시행령 제5조의 별표 1은 없는 내부 본문 창 대신 공식 첨부파일을 열도록 했다.

## 보존 및 검증

공개 자료는 별도 새 폴더에서 증분 생성한다. 대응 원본과 공개판의 법령명·시행일·공식 출처 URL·조문 순서·제목·본문·삭제 상태를 대조한 뒤 별표 메타데이터를 사용한다. 기존 조문 본문과 연결 행은 유지하고 새로운 별표 번호 근거만 추가한다. 원문 인용 위치와 실제 문구를 대조하고, 별표 내부 분석이 늘지 않았는지도 확인한다.

분야 간 연결, 과거 판본 비교, 기존 PDF 분석, 국유재산 특례 목록 및 지역별 조례 자료는 기존 참조를 유지한다. 공공기관 추가 문서 중 원본 메타데이터가 없는 자료는 공개 본문과 기존 연결을 유지하며, 다른 분야에서 동일 판본이 확인될 때만 별표 메타데이터를 재사용한다. 다른 분야의 태그나 분석 정책은 이식하지 않는다.

공식 파일의 이동·접근 제한까지 없애는 기능은 아니다. 수집 범위 밖 자료나 불명확한 소속을 임의로 연결하지 않으며, 번호 연결이 없다고 별표와 무관하다는 뜻은 아니다.

### 2026-09-29 공개판 대조 결과

- 15개 분야, 11,618개 문서의 조문 266,231개를 기존 공개판과 전수 대조했다. 본문·제목·시행일·삭제 상태·순서를 보존했다.
- 기존 수집 연결 514,243건과 지도 밖 인용 128,248건의 증거를 유지했다. 추가한 별표·서식 번호 근거는 5,391건(수집 연결 5,297건, 지도 밖 인용 94건)이며, 이는 별표 수나 조문 수가 아닌 **인용 위치별 근거 수**다.
- 새 근거의 원문 문구와 위치가 전수 일치했다. 기존 별표 본문 분석 7개, 조달 PDF 2개, 국유재산 특례 목록, 지역 카탈로그 264개와 분야 간 자료를 그대로 유지했다.
- 기존 판본을 참조하는 분야 간 자료는 별도 파일을 유지하므로, 파일 단위 검증기의 조문 합계에는 같은 본문의 중복이 포함될 수 있다. 위 조문 수는 현재 분야 카탈로그 기준이다.
- 파이썬 회귀시험 69개 모듈 및 별표 링크·본문 열람 관련 자바스크립트 시험 32개를 통과했다. 은행법 시행령·근로기준법 시행령·요양급여 기준 규칙의 연결 카드와 기존 법인세법 시행규칙 별표 본문 창을 실제 화면에서 확인했다.
