# 공개 앱 누적 조회수

2026-09-28 구현. 사이드바 아래에 **누적 조회**를 표시한다. 2026-09-28 공개판부터 집계하며, 도입 전 방문 기록을 복원하지 않는다.

[Hits 공식 사용법](https://github.com/silentsoft/hits)의 SVG 카운터를 사용한다. 계정·인증키·유료 서버를 추가하지 않는다. 서비스 제공자가 중단하거나 이용 조건을 바꿀 수 있으며 통계의 영구 보존을 보장하지 않는다.

## 집계 단위

- HTTPS의 `gschamisle.github.io/law-orbit/` 및 `index.html`에서 앱을 열 때 한 번 요청한다.
- 새로고침은 다시 집계할 수 있다. 분야·조문·필터 전환은 추가 집계하지 않는다.
- 개발 미리보기·내려받은 HTML·소개문·지도 iframe·공공 GitLab에서는 요청하지 않는다.
- 계수는 고유 방문자 수가 아닌 이미지 요청 기반 참고 조회수다. 통신 차단·봇·직접 호출 때문에 실제 이용과 다를 수 있다.
- 공개 식별자는 `gschamisle.github.io/law-orbit`이며, 테스트는 별도 `law-orbit-counter-integration-test`로 분리했다. 임의 초기값 가산 옵션은 사용하지 않는다.

## 데이터와 장애 처리

선택 법령·조문·검색어·URL 쿼리/해시·문서 내용은 집계 주소에 넣지 않는다. 이미지 요청에는 `no-referrer`를 지정한다. 앱에서 추적용 쿠키나 방문자 식별자를 만들지 않는다. 집계 서버는 통신을 받는 외부 서비스이다. [제공자의 개인정보 안내](https://hits.sh/privacy/)는 배지 카운터가 IP·쿠키·사용자 에이전트를 추적하지 않는다고 설명하며, 제공자의 별도 웹사이트는 다른 분석 정책을 사용한다.

외부 집계 장애는 앱 열람을 막지 않는다. 조회수를 0이나 임의 숫자로 대체하지 않고 연결 상태를 표시한다. 오프라인 요청을 보관했다가 추후 전송하지 않는다.

## 검증과 운영

- 공식 배지 응답: 별도 테스트 키에서 HTTP 200, SVG, `no-store` 확인.
- 허용 공개 주소, 미리보기·오프라인·iframe 제외, 쿼리 미전송, 중복 마운트 및 실패 처리 테스트 3개 통과.
- 실제 공개 앱의 집계 증가는 배포 이후 확인할 항목이다. 이번 검증은 실서비스 계수를 올리지 않았다.
- 게시 파일 1개(`pageviews.mjs`) 추가. 서비스 워커는 외부 카운터 응답을 저장하지 않는다.

향후 고유 방문자 수·날짜별 이용·유입 경로가 필요하면 계정 기반 분석 서비스로 전환하는 편이 적합하다.
