# 보안 운영

## 로컬 문서 검토

공개 GitHub Pages에는 파일 업로드·문서 변환 서버가 없다. 개정안 검토는 로컬 앱에서 사용한다. 기본 설정과 권장 실행 명령 `python -m scripts.run_fsc_preview`는 127.0.0.1에만 연결한다.

- 업로드 파일명에는 경로·제어 문자·대체 데이터 스트림 표기를 허용하지 않는다.
- 앱이 내용 해시로 저장 이름을 만들며, 같은 이름의 다른 문서를 덮어쓰지 않는다. 업로드 크기는 50MB 이하로 제한한다.
- PDF 변환은 미리 설치한 고정 버전 kordoc의 JavaScript 파일을 Node로 직접 실행한다. 셸, 배치 파일, npx 자동 설치를 거치지 않는다.
- `npm ci --prefix tools/document-converter --ignore-scripts`로 잠금 파일에 기록된 패키지를 설치한다. 패키지 설치 스크립트는 실행하지 않는다.
- 변환 제한 시간은 180초다. 실패·시간 초과 시 기존 변환 캐시를 보존하고 불완전한 결과를 재사용하지 않는다.
- 임의 파일을 안전하게 실행하는 샌드박스는 아니다. HWP/HWPX·PDF 추출 라이브러리의 보안 업데이트는 계속 필요하다.

## 공개 자료 경계

의견 문서 6개는 로컬 백업을 만든 뒤 현재 Git 추적에서 제외했다. 공개 배포 파일에는 포함되지 않는다. `scripts.test_upload_security`가 output·업로드·의견 원문·주요 비밀 파일의 재유입을 차단한다.

현재 파일에서 제거하는 것과 과거 Git 이력을 다시 쓰는 것은 별개다. 과거 커밋·태그·포크·캐시의 사본까지 삭제됐다고 주장하지 않는다. 이력 재작성은 백업과 영향 검토 후 별도로 진행해야 한다.

## GitHub 보호

비밀정보 탐지·푸시 차단을 유지하고, 의존성 취약점 알림·자동 보안 수정 PR을 사용한다. Dependabot은 Python, 로컬 PDF 변환기, GitHub Actions를 주간 점검한다. 보안 수정 PR도 시험을 통과한 뒤 병합한다.

Actions는 공식 저장소에서 확인한 전체 커밋 SHA로 고정한다. 토큰의 기본 권한은 읽기로 제한하며 Pages 배포 작업에만 필요한 쓰기 권한을 부여한다. 메인은 PR과 `offline-tests` 확인을 거치고 강제 푸시·삭제를 막는 정책을 적용한다. 혼자 관리할 수 있도록 다른 사람의 승인을 필수로 요구하지는 않는다.

계정 2단계 인증·복구 수단·개인 접근 토큰의 보관은 저장소 설정과 별개다. GitHub 경고가 없거나 시험이 통과했다는 사실은 모든 취약점이 없다는 보증이 아니다.
