# 국유재산

> 현재 상태 (2026-09-21): 11개 분야 전체 공개 베타에 포함했습니다. 아래 날짜별 미리보기·미배포 표기는 당시 작업 기록입니다.

국유재산의 인용망과 **국유재산특례제한법 별표의 등재 관계**를 따로 탐색합니다. 기존 여섯 분야의 자료를 합치지 않으며, 같은 법률이 다른 분야에도 있으면 서로 다른 문서 ID와 화면 상태를 사용합니다.

## 실제 수집 결과 — 2026-09-20

- 기본 법령 5개: 국유재산법·시행령·시행규칙, 국유재산특례제한법·시행령.
- 제목에 국유재산·국유일반재산·국유증권·국유농지·국유지가 들어가는 재정경제부/기획재정부 소관 행정규칙 15개.
- 별표에 적힌 정확한 법률명을 법제처 API로 다시 조회하여 근거 법률 183개 추가 수집. 본문은 총 203개 문서·10,807개 조문.
- 인용 분석 범위는 830개 조문, 내부 인용 근거 2,390건. 미수집 대상 인용 2,362건은 별도 표시.
- 별표 222개 항목 중 법률명·조 번호 대조 216개, 근거 법률 미수집 4개, 특정 개정법 부칙 확인 대상 2개. 항·호·목의 적용 요건까지 일치한다고 판정한 수치가 아닙니다.
- `국유재산위탁개발사업 회계처리지침`은 본문만 보관하며 조문 연결 미분석입니다.

별표는 법제처 본문 API가 제공한 4열 표를 파싱합니다. 연번 연속성, 열 수, 날짜, 원문 오프셋과 해시를 검사하고, 2026-07-01 시행 판본(법령 일련번호 283411)의 원문·별표 다운로드 링크를 보존합니다. 유형은 사용료등 감면, 장기 사용허가·대부, 양여의 복수 태그입니다. 유형별 제한 문구도 원문에 남깁니다.

## 탐색

전체 지도는 국유재산법·국유재산특례제한법을 중앙에 둔 나선형 배치를 사용합니다. 법령·조문 점과 인용 근거를 그대로 보존한 시각적 배치이며 법적 위계를 뜻하지 않습니다. 세부 분야만 볼 때는 화면 크기에 맞게 확대합니다.

1. **국유재산** 메뉴에서 법령·규정과 조문을 고릅니다. **전체 은하**는 분야 전체 지도, **연결 탐색**은 선택 조문의 직접 인용·역인용입니다.
2. **국유재산 특례 목록**에서 법률명·조문·날짜, 유형, 별표상 기한, 대조 상태로 좁힙니다.
3. **제○조 본문**은 현재 지도 중심을 유지한 채 근거 조문을 엽니다. **이 조문을 중심으로 탐색**을 누르면 중심을 바꿉니다.
4. 특례제한법 본문 아래의 버튼은 전체 별표, 다른 조문 아래의 버튼은 해당 조문의 등재 항목을 엽니다.
5. 국유재산 분야의 **이 법령 오프라인 저장**에는 특례 목록도 포함됩니다. 다른 근거 법률의 본문은 그 법률을 읽거나 저장해야 오프라인에서도 열립니다.

## 수집·분석 범위와 한계

- 기본 법령·선정 행정규칙은 조문별 인용을 분석합니다. 근거 법률은 별표 등재 조문 및 기본 법령을 직접 인용하는 조문에서 발생하는 인용만 지도에 넣습니다. 그 밖의 본문은 열람할 수 있으나 분석 범위 밖임을 알립니다.
- 별표 등재를 직접 인용선으로 만들지 않습니다. 기한 경과는 수집 기준일과 표에 적힌 날짜의 비교이며, 법적 효력 상실이나 개정 의무를 확정하는 표시가 아닙니다.
- 미수집 법률명 3개(별표 항목 4개): `2023 순천만국제정원박람회 지원 및 사후활용에 관한 특별법`, `신에너지 및 재생에너지 개발ㆍ이용ㆍ보급 촉진법`, `폐광지역 개발 지원에 관한 특별법`. 현재 명칭이 다른 검색 결과를 임의로 동일 조문에 연결하지 않았습니다.
- 현재 목록 조회에서 뒤의 두 옛 법명에 대응하는 검색 결과로 각각 `재생에너지 개발ㆍ이용ㆍ보급 촉진법`, `석탄산업전환지역 개발 지원에 관한 특별법`이 확인되었습니다. 명칭 변경 이력과 별표 근거 조문의 승계 대조는 후속 작업입니다.
- 법률 제10710호·제16160호의 특정 개정법 부칙 2개는 현행 본문의 제2조·제5조로 치환하지 않습니다. 역사 판본 수집·분석은 미구현입니다.
- 모든 부처의 국유재산 훈령·조례·특별법, 다른 별표·첨부 본문, 부칙·경과조치, 의미상 연결을 전수 분석한 것은 아닙니다.
- 자동 예약 갱신·공개 배포는 연결하지 않았습니다. 기존 국세·금융 자동 갱신 설정은 유지합니다.

## 실행

기존 `LAW_API_KEY` 또는 `LAW_OC` 환경변수·로컬 설정을 재사용합니다. 인증값은 출력하지 않으며, 수집 결과는 Git에서 제외된 `output/state_property-universe/`에만 저장합니다.

```powershell
python -m scripts.test_state_property
python -m scripts.collect_state_property_universe --stage inventory
python -m scripts.collect_state_property_universe --stage core
python -m scripts.collect_state_property_universe --stage annex
python -m scripts.collect_state_property_universe --stage related
python -m scripts.collect_state_property_universe --stage build
```

각 단계는 같은 날짜의 `staging/YYYYMMDD`를 사용합니다. 검증 실패 시 기존 bundle을 보존합니다. 이미 잠금이 있으면 다른 수집을 중단하거나 잠금을 삭제하지 않습니다. 국회/국회사무처의 목록·본문 기관 표기 차이는 확인한 `국회사무처법`과 `대한민국헌정회 육성법` 두 건에만 한정하여 허용합니다.

기존 여섯 분야의 검증된 정적 배포본에 추가할 때:

```powershell
python -m scripts.build_state_property_site --base-site C:\Users\gscha\codexproject\LawGalaxy-Static\output\static-site-v2 --destination output\static-property-preview
python -m scripts.validate_static_galaxies output\static-property-preview
python -m http.server 8512 --bind 127.0.0.1 --directory output\static-property-preview
```

대상 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 기존 manifest의 여섯 항목과 압축 자료는 그대로 복사하고 해시로 검증합니다. 전체 구축은 각 분야 bundle을 한 소스 루트의 독립 폴더에 준비한 뒤 기존 `scripts.build_static_galaxies`를 사용할 수도 있습니다.

## 검증 기록 — 2026-09-20

- 오프라인 회귀 스위트 45개 모듈 통과. 원본 로컬 자료가 새 작업 폴더에 없는 기존 화면 통합 테스트 11개는 미실행(사유 표시 후 건너뜀).
- 국유재산 전용 테스트 최종 20개 통과: 표 누락·날짜 오류, 개정법 부칙의 오연결, 범위 끝 조문 누락, 근거 변조, 분석 범위, 미수집 안내, 실제 인용·역인용, 분야 상태 복원 등.
