### 중앙 법령 18개 계열

- 핵심: 국토계획법, 건축법, 주택법, 도시개발법, 도시정비법, 공공주택 특별법
- 관리·정비: 건축물관리법, 공동주택관리법, 소규모주택정비법, 민간임대주택법
- 계획: 개발제한구역법, 토지이용규제 기본법
- 관련 인허가: 농지법, 산지관리법, 도로법, 하천법, 수도법, 하수도법

각 법률의 시행령·시행규칙을 포함한다. 주택건설기준에 관한 규정·규칙, 주택공급규칙, 건축물 피난·방화구조·설비·구조 규칙, 도시·군계획시설규칙 등 별도 명칭 7건도 수집한다. 정식 명칭과 공식 약칭은 API 값으로 보관한다. 지도에서는 약칭을 쓰고 상세 정보에서 정식 명칭을 확인할 수 있다.

### 핵심 행정규칙 12건

공공주택 업무처리지침, 건축물의 에너지절약설계기준, 공동주택 분양가격의 산정 등에 관한 시행지침, 주택건설공사 감리자지정기준, 소규모주택정비사업의 시공자 및 정비사업전문관리업자 선정기준은 실제 조문 단위로 분석한다.

다음 7건은 본문을 수집했지만 장·절·항목 형식이므로 조문 연결 미분석 상태로 원문만 열람한다.

- 개발행위허가운영지침
- 광역도시계획수립지침
- 도시·군관리계획수립지침
- 도시·군기본계획수립지침
- 도시·주거환경정비기본계획 수립 지침
- 도시개발업무지침
- 지구단위계획수립지침

## 확인할 만한 예시

- **주택법 제19조**: 수집 범위 안 인용 32건, 역인용 10건. 건축법·국토계획법·농지법·산지관리법·도로법·하천법 등 인허가 연결을 확인한다.
- **건축법 제11조**: 인용 26건, 역인용 131건. 조례 위임·참조 문구와 인허가 의제 문맥이 함께 표시된다.
- **국토계획법 제56조**: 인용 2건, 역인용 50건. 개발행위허가와 관련된 다른 분야의 연결을 확인한다.
- **공공주택 업무처리지침 제2조**: 공공주택 특별법 제6조부터 제32조의4까지의 범위 인용이 실제 수집 조문별로 펼쳐진다. 법 제17조에서 지침의 역인용도 확인할 수 있다.

수치는 해당 수집 판본에서 문맥 확인 후보를 포함한 값이다. 화면의 방향·연결 종류 필터에 따라 보이는 수는 달라질 수 있다.

## 실행

기존 미리보기: <http://127.0.0.1:8503/>

```powershell
cd C:\Users\gscha\codexproject\FscLawGalaxy-Stage2
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8503
```

수집·검증·게시:

```powershell
.\.venv\Scripts\python.exe -m scripts.collect_housing_universe --stage inventory
.\.venv\Scripts\python.exe -m scripts.collect_housing_universe --stage collect
.\.venv\Scripts\python.exe -m scripts.collect_housing_universe --stage build
# 세 단계를 순서대로 모두 실행하려면 --stage all
```

기존 LAW_API_KEY / LAW_OC 환경변수 또는 로컬 `.env` 인증을 재사용한다. 인증값은 저장 자료·로그·Git에 넣지 않는다. 목록 페이지 개수·총수·기관·동일 판본 여부와 본문 이름·ID·시행일을 검증한다. 원문 인용의 시작·끝 위치도 전체 검증한다. 모든 검증을 통과한 뒤 `bundle.json`을 원자적으로 교체한다. 오류 시 기존 게시 자료를 보존하며 잠금 충돌 시 다른 실행을 중단하거나 잠금을 삭제하지 않는다.

## 이번 범위 밖

- 전국 조례 본문·역인용: **미수집**. 중앙 법령의 조례 위임·참조 문구만 표시한다.
- 모든 국토부 훈령·고시·건설기준, 모든 관련 부처 법령: 전체 수집을 주장하지 않는다.
- 위의 항목형 지침 7건, 별표 본문·첨부파일·부칙의 조문 연결 분석: **미구현**.
- 문언상 직접 인용이 없는 유사 문구·정책상 영향 분석: **미구현**.
- 국토·건축·주택 자동 갱신 예약: **미연결**. 기존 세법·금융법 예약은 변경하지 않았다.
- 새 분야의 법령안 업로드 검토 확장: 이번 작업에 포함하지 않았다. 기존 개정안 검토 화면은 유지한다.
