# 세법 은하 수록 범위

## 2026-09-16 수집본

국가법령정보센터의 시행일 기준 본문 API(`target=eflaw`, 법령 ID)를 사용했다.
105개 법령과 32,587개 연결을 수록한다. 연결 수는 인용 위치와 대상을 구분한 건수이며,
서로 다른 개정 의무의 수를 뜻하지 않는다. 자동 갱신 일정은 설정하지 않았다.

| 분류 | 범위 |
| --- | --- |
| 세법령 49개 | 기존 11개 법률군에 증권거래세법·개별소비세법·교육세법·주세법·교통·에너지·환경세법·인지세법 및 존재하는 하위 법령 추가 |
| 외부 법령 56개 | 상법·자본시장법, 중소기업기본법·공정거래법, 민법·회생파산법·민사집행법, 외부감사법·신탁법, 벤처투자법·벤처기업법·중소기업창업지원법, 민간임대주택법·주택법·도시정비법·공공주택법·소규모주택정비법, 은행법·보험업법·여신전문금융업법·근로자퇴직급여보장법의 법률군 및 회생·민사집행 법원규칙 |

정식 법령명·ID·일련번호·시행일·공포일·원문 해시는 자료의 `catalog`와 수집 원문에 저장한다.
원문 XML은 로컬 캐시이고, 공개 본문과 계층/별표 메타데이터를 정규화한 JSON은 재빌드용 자료다.
API 인증값을 파일이나 원문 링크에 넣지 않는다.

## 사용

1. **세법 관계도 → 법령 은하 (3D)**에서 개정할 법령과 조문을 입력한다.
2. **조문 연결 보기**를 누르면 직접 인용·역인용 경로만 부각된다.
3. **외부 법령 연결 함께 보기**로 범위를 조절한다. 전체 은하는 세법령을 안쪽, 외부 법령을 바깥쪽에 배치한다.
4. **은하 표시 설정 → 연결 종류**에서 조문 / 법령·정의·산식 / 별표·서식 / 분류·회계기준을 선택한다.
5. 연결된 점을 선택하면 출처 항·호·목, 인용 문구, 주변 원문, 시행일과 공식 원문 링크가 나온다.
6. 법령 전체를 참조한 역인용은 별도 선택으로 펼친다. 특정 조문과의 연결을 확정한 것으로 취급하지 않는다.

별표는 이름과 내려받기 링크를 연결하고, 분류·회계기준은 참조 사실을 표시한다.
점선은 한정·제외·대체·상대 참조 또는 넓은 범위의 확인 후보다.
나눔명조 글꼴과 기존 개정안 파일 업로드 검토를 유지한다.

## 자료 경로와 갱신

- `data/law-galaxy-sources.json`: 수집한 공개 본문, 조항호목 위치 및 별표 메타데이터.
- `data/law-galaxy-graph.json`: 은하·조문 영향 탐색·평면 관계도용 그래프.
- `data/law-galaxy-snapshots/`: 재수집을 줄이는 XML/JSON 캐시. Git에서 제외한다.
- 기존 `data/law-citation-graph.json`과 병행 매트릭스는 업로드 검토용으로 유지한다.

```powershell
# Windows 사용자 환경변수에 이미 등록한 값을 프로세스에 전달한다.
$env:LAW_API_KEY = [Environment]::GetEnvironmentVariable('LAW_OC', 'User')
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe -m scripts.collect_law_universe
.venv/Scripts/python.exe -m core.universe_builder
.venv/Scripts/python.exe -m scripts.run_offline_tests
```

수집 실패 시 기존 통합 원문을 덮어쓰지 않는다. 원문 갱신 뒤 그래프도 재생성해야 한다.
그래프만 조회할 때는 API 키와 외부 통신이 필요 없다.

## 범위와 한계

- 세법령 내부 및 세법령↔선정 외부 법령의 연결을 다룬다. 외부 법령끼리의 일반 법체계는 확장하지 않았다.
- 미수록 법령은 원문 언급 목록으로 남긴다. 현재 전체 국내 법령을 완전히 포괄하지 않는다.
- 별표 파일의 표·이미지 본문, 부칙, 고시·감독규정·가이드라인, 분류·회계기준 전문을 전수 해석하지 않는다.
- 조문 존재·폐지·과거 버전의 동일성, 모든 상대 참조와 복합 문맥을 자동 확정하지 않는다.
- 그래프는 직접 연결을 보여준다. 간접 연쇄개정과 입법 취지에 따른 개정 필요성은 추가 검토 대상이다.
- 현행본 수집 시점과 사용자가 검토할 개정안의 기준시점이 다를 수 있다. 시행일과 근거를 함께 확인한다.
