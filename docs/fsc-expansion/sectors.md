# 금융법은하 업권 확장 — 검증 보고서

2026-09-16 · 작업 브랜치 `codex/fsc-expansion-stage2` · 커밋·푸시 없음

## 구현 결과

기존 전체 금융법은하 아래에 **보험 / 은행 / 증권·자산운용 / 여신·서민금융 / 전자금융·가상자산 / 공통** 메뉴를 추가했다. 개정안 검토와 세법은하 메뉴는 유지한다.

금융위 감독규정과 금감원 시행세칙을 조문 단위로 분리하여 공통 인용 그래프에 포함한다. `제1-2조`, `제2-9조의2`, 항·호 및 범위 인용을 지원한다. 본문의 명시적인 별칭 정의를 읽어 “법”, “영”, “규정”, “감독규정”을 해석하고 원문 인용 위치·시행일·수집 판본 링크를 보존한다. 삭제 표제와 기간 표현을 구별하며, 해결되지 않은 별칭·상대 참조·없는 대상 번호는 검토 상태를 남긴다.

업권은 문서별 `sectors` 배열로 저장한다. 분류 기준은 `core/fsc_sectors.py`의 명칭 규칙이며 `sector_basis`에 근거를 남긴다. 예를 들어 퇴직연금감독규정과 시행세칙에는 보험·은행·증권 태그를 함께 부여한다. 분류는 탐색을 위한 편집 규칙이며 법적 적용 범위를 확정하지 않는다. 별도 수동 태그 편집 화면은 구현하지 않았다.

업권 전체 지도에는 그 업권 문서를 보여준다. 특정 조문 검색은 금융법 전체 그래프를 대상으로 수행하여 다른 업권과 공통규정의 직접 인용·역인용이 빠지지 않게 한다. 해당 연결에는 **분야 밖 관련 조문** 배지와 별도 근거표를 표시한다. 본문이 없는 외부 법령은 지도에 펼치지 않으며, 본문만 수집한 미분석 규정과 완전 미수집 대상을 구별한다.

검색 법령·번호·필터·선택 상태와 캐시 키는 업권별로 분리하고 메뉴 복귀 시 복원한다. 약칭 표시, 나눔명조, 3D 시각화는 유지한다.

## 실제 수집·분석

인증값은 기존 환경/로컬 설정에서 재사용했다. 법제처 목록과 본문의 문서 ID·판본·시행일·기관을 대조했다. 오늘 검증된 기존 본문 캐시는 재사용하고 금감원 시행세칙 28건을 실제 API로 추가 수집했다. 세법 원문을 빌리거나 합치는 옵션은 사용하지 않았다.

업권별 지도 문서는 보험 14, 은행 22, 증권·자산운용 30, 여신·서민금융 40, 전자금융·가상자산 19, 공통 148건이다. 복수 태그 때문에 합계는 전체 문서 수와 다르다.

금감원 수집 범위는 `core/fsc_bylaws.py`의 명시된 28개 시행세칙이다. 법제처 현행 ‘시행세칙’ 검색 207건 전체 페이지를 확인한 뒤 지정 명칭과 금감원 소관을 대조했다. 모든 금감원 내부 규정을 전수 수집했다고 주장하지 않는다. 지정 시행세칙이 목록에서 빠지거나 필수 감독규정·시행세칙 분석이 실패하면 새 번들을 완료 처리하지 않는다.

## 실제 화면에서 확인한 예

- 보험업감독규정 제7-1조 ← 보험업감독업무시행세칙 제5-7조의3. 지도에서 역인용 문구와 양쪽 판본 링크를 확인했다.
- 금융투자업규정 제3-25조 ← 금융투자업규정시행세칙 제2-9조제1항. 실제 그래프의 역인용을 검증했다.
- 보험업감독규정 제4-10조제4항 → 은행법 제2조제1항제2호. 지도에 ‘분야 밖 관련 조문’으로 표시된다.
- 보험 메뉴 검색 후 은행 메뉴는 별도의 기본 조문을 유지했고, 보험으로 돌아오면 기존 검색이 복원되었다.

## 검증

- 전체 오프라인 회귀 테스트 **33개 모듈 통과**: 기존 세법·개정안 검토 포함.
- 마지막 별칭 처리 보완 후 금융법 관련 **23개 테스트 추가 통과**.
- 실제 저장 인용 **37,783건**의 시작·끝 위치가 본문 문자열과 일치함을 전수 확인했다. 별표 표제 인용은 이 숫자에서 제외한다.
- 해석 보류 **1,137건**의 원문 위치도 대조했다.
- 보험·은행·증권의 시행세칙 ↔ 감독규정 양방향 탐색, 복수 태그, 교차 업권 표시, 데이터 부재 시 세법 대체 금지, 업권·세법 상태 분리를 확인했다.
- 원래 세법 저장소의 브랜치·HEAD·작업 상태 및 데이터 파일 11개의 SHA-256이 유지되었다. 금융위 작업 폴더의 기존 `data` 파일 11개도 변하지 않았다.
- 인증값이 변경 파일·번들·검증 로그에 포함되지 않고 `.env`가 추적되지 않음을 확인했다.
- 새 실제 개정법률안 업로드부터 결과까지의 수동 검토는 **미실행**이다. 기존 업로드 화면과 회귀 테스트는 유지·통과했다.

## 미분석 범위와 원문 오류

14개 행정규칙 본문은 조문 분석에 넣지 않았다. 13건은 조문 표제 형식이 없는 요율·기준·지침 등이고, **정보분석심의회 운영규정**은 공식 본문에 다른 제목의 제4조가 두 번 있어 번호를 확정할 수 없다. 번호를 임의 변경하지 않고 원문과 미분석 사유를 보존했다. 정확한 목록은 `output/fsc-universe/sector-verification.json`의 `unindexed`에 있다.

부칙, 별표 파일 본문, 미수집 외부 법령의 본문·역인용, 모든 지역적 별칭·상대 참조의 완전 해석은 미구현이다. 직접 인용 관계가 동시개정 의무를 확정하지는 않는다.
