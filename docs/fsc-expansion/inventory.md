# 금융위 법령 인벤토리 — 1차 seed

기준일: 2026-09-16  
상태: **부분 인벤토리**. 금융위원회 공식 소관법규 화면은 현재 117건/12페이지를 표시하지만, 이 파일은 1차 구현과 우선순위 검증에 필요한 법률명만 담는다. 법령 ID·MST·시행일은 코딩으로 추정하지 않고 다음 수집 단계에서 `eflaw`로 해결한다.

## 별도 관리할 규범 레이어

| 레이어 | 현재 상태 | 다음 수집 방법 |
|---|---|---|
| 법률·대통령령·총리령 | seed 일부 확인 | FSC 117건 전수 → `eflaw` 정확 ID/시행본 해결 |
| 금융위 훈령·예규·고시·지침 | 미수집 | `admrul` + 소관부처/종류 필터, FSC 게시판 cross-check |
| 금융위 게시판의 공고 | 미수집 | 규범성 공고와 등록·처분성 공고를 분리 후 필요한 것만 수록 |
| 금융감독원 시행세칙 등 | 미수집 | 금감원 공식 원문과 발령주체·버전 식별 후 별도 corpus |
| 타부처 법령 역인용 | 미수집 | 기존 세법 은하 → 금융위 전체 → 전체 현행 법령 순으로 확대 |

## 이미 확인되는 세법 bridge

현재 세법 은하의 외부 법령군에는 `자본시장과 금융투자업에 관한 법률`, `은행법`, `보험업법`, `여신전문금융업법`, `주식회사 등의 외부감사에 관한 법률`이 포함돼 있다. 따라서 금융위 확장 첫 단계부터 두 우주를 새로 조인할 필요 없이 동일 canonical name/공식 ID로 연결 여부를 검증할 수 있다.

`금융실명거래 및 비밀보장에 관한 법률`은 FSC 목록에 `금융실명거래및비밀보장에관한법률부칙제7조의규정에의한소득세등의계산방법에관한규칙`이 별도로 존재한다. 이 항목은 **단순히 "금융실명법 시행규칙"으로 생성할 수 없는 이름의 하위 규범**이므로 이름 추정 금지 원칙의 golden case로 삼는다.

## 아직 확정하지 않은 것

- 이 표를 금융위 소관 **전체 법률** 목록이라고 보지 않는다.
- seed 단계에서는 법령 ID, MST, 최신 시행일을 코드 상수로 넣지 않는다.
- 시행령/시행규칙/감독규정의 parent-child 관계를 이름만으로 확정하지 않는다.
- 금융감독원 규정과 금융위 행정규칙을 동일 issuer로 취급하지 않는다.
- 실제 그래프를 만들기 전에는 허브 중심성, 역인용 건수, "개정필요 N건"을 산출했다고 표현하지 않는다.
