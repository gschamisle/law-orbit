# 지방세 은하와 지역 조례

법령은하 메뉴의 **지방세** 탭에서 중앙 지방세 법령과 지자체 조례·규칙의 직접 인용과 역인용을 탐색한다. 기존 세법·금융법 데이터와 선택 상태는 독립되어 있다.

## 사용

1. 기본 화면은 지방세기본법·지방세징수법·지방세법·지방세특례제한법과 각 시행령·시행규칙이다.
2. 법령과 조문을 선택해 **연결 탐색**을 누른다. 수집 본문에서 검색·선택할 수도 있다.
3. **이 조문을 인용하는 지역**에서 지자체를 골라 **이 지역 펼치기**를 누른다.
4. 선택 지역의 조례·규칙이 중앙 법령과 함께 표시된다. 직접 인용·역인용 근거, 시행일, 수집 판본 공식 링크를 확인한다.
5. 지도에 연결이 없는 검색 후보도 법령·조례 선택과 수집 본문에서 읽을 수 있다. 선택 지역 밖 조례를 자동으로 합치지 않는다.

기본 화면은 중앙 법령만 표시한다. 전국 역인용 색인은 확인한 조문별로 읽으며, 모든 지역의 조례를 하나의 거대한 지도에 펼치지 않는다. 화면 및 내려받은 HTML은 마루부리와 Pretendard, 터치 조작, 소리 설정을 공통 시각화에서 재사용한다.

## 수집·판본 대조

- 자치법규 목록 API `ordin`, `nw=1`의 전체 페이지를 받는다. 페이지별 행 수·총수·고유번호와 시작/종료 목록을 대조한다. 동시 수정이 가능한 API이므로 원자적인 전국 시점 스냅샷이라고 표현하지 않는다.
- API가 동일 자료를 중복 반환하면 개별 명칭 검색에서 동일 중복이 재현될 때만 중복 원인을 기록한다. 근거 없는 페이지 중복이나 판본 충돌은 수집을 중단한다.
- 본문 검색 `지방세`의 모든 결과 페이지를 수집하고, 전체 목록에서 지방세·시세·도세·군세·구세·납세자·세무조사 제목을 보완한다.
- 실제 본문 검색에는 과거 판본이 섞인다. 검색 결과의 고유번호를 독립적으로 받은 현행 목록에 연결한 뒤 그 판본의 MST로 본문을 받는다. 가장 큰 번호를 임의로 현행 판본으로 선택하지 않는다.
- 현행 목록에서 확인할 수 없는 검색 결과, 시행예정·날짜 미확인·폐지 자료, 수집 실패는 별도 장부에 남긴다. 분석하지 않은 자료를 영향 없음으로 처리하지 않는다.
- 전국 목록 전체를 받은 것과 전국의 지방세 관련 조례를 전부 식별한 것은 다르다. 제목·본문 검색에 걸리지 않는 의미상 의존관계와 지자체 공보의 반영 지연은 별도 점검 대상이다.

## 분석과 한계

공통 인용 엔진의 조·항·호·목/범위 해석, 인용 근거 위치, 직접 인용·역인용 분석을 재사용한다. 조례는 문서의 목적·정의 조문과 해당 조문의 명시적 별칭 선언으로 `법`, `영`, `조례` 등을 해석한다. 불확실한 별칭·상대 참조는 확인 목록에 남긴다.

- 외부 법령과 다른 지역의 미수집 조례는 인용 문구·공식 링크·미수집 상태로 보존한다. 그 본문·역인용을 점검했다고 표시하지 않는다.
- 부칙은 원문 저장만 하며 연결 분석은 하지 않았다.
- 별표·별지 참조는 근거로 남기되 파일 본문은 미분석이다. 법제처 본문 API 가이드에도 별표 제공 범위의 제한이 있다.
- 문구 유사성, 일반규정의 묵시적 적용, 위임의 법적 범위, 연계개정 의무는 자동 확정하지 않는다.
- 지자체 공보와의 전수 대조, 전국 별표 보완 수집, 의미상 영향 분석은 미구현이다.
- 기존 세법·금융법 예약 갱신은 유지된다. 지방세 수집은 아래 명령으로 별도 실행하며 기존 예약에 자동으로 추가하지 않았다.

## 실행

프로젝트 폴더에서:

```powershell
.\.venv\Scripts\python.exe -m scripts.collect_local_tax_universe
```

네트워크 수집과 그래프 생성을 따로 실행할 수도 있다.

```powershell
.\.venv\Scripts\python.exe -m scripts.collect_local_tax_universe --collect-only
.\.venv\Scripts\python.exe -m scripts.collect_local_tax_universe --build-only --as-of 20260917
.\.venv\Scripts\python.exe -m scripts.test_local_tax_collection
.\.venv\Scripts\python.exe -m scripts.test_local_tax_graph
```

`--as-of`는 이미 수집한 날짜를 지정하는 빌드 재개 용도다. 인증은 기존 프로세스·프로젝트 `.env`·Windows 사용자 환경변수의 `LAW_API_KEY` 또는 `LAW_OC`를 재사용한다. 인증값을 명령 인자·산출물에 넣지 않는다. API가 응답 링크에 돌려주는 `OC`도 저장 전에 제거한다.

산출물은 Git에서 제외된 `output/local-tax-universe/`에만 저장한다.

- `staging/<날짜>/`: 페이지별 목록, 후보, 판본 대조, 본문 수집 상태.
- `body-cache/`: 공식 판본별 원문과 무결성 확인용 해시.
- `versions/<버전>/`: 중앙 지도, 지역별 지도, 중앙 조문별 전국 역인용 색인, 수집 범위.
- `current.json`: 모든 지역과 인용 근거를 검증한 뒤 교체하는 공개 버전 포인터.

기존 `data/`, `output/tax-universe/`, `output/fsc-universe/`는 이 수집기가 쓰지 않는다. 실패 시 기존 공개 버전이 유지된다. 최초 데이터가 없을 때 다른 은하나 가상 자료로 대체하지 않는다.

공식 문서: [자치법규 목록 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinListGuide), [본문 API와 별표 제공 범위](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ordinInfoGuide).
