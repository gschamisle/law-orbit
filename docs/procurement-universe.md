# 조달·계약 은하

## 사용

미리보기 `http://127.0.0.1:8503/` → **법령은하 → 조달·계약**.

- 기본 분야: **국가계약 · 재경부**. 조달청 집행기준 / 지방계약 / 전체 연결로 전환할 수 있다.
- 법령·예규를 선택하고 조문 번호를 입력하거나 **수집 본문에서 조문 찾기**로 본문을 읽고 선택한다.
- **연결 탐색**은 전체 조달·계약 수집 범위에서 직접 인용과 역인용을 찾는다. 다른 계약 분야의 조문은 **분야 밖 관련 조문**으로 표시한다.
- 원문 문구·문맥·시행일·수집 판본 공식 링크를 확인하고 HTML 지도 또는 JSON 인용 근거를 내려받을 수 있다.
- 기본 지도는 법령·예규 묶음별 색상이다. 본법·시행령·시행규칙은 같은 색이며 분야를 전환해도 색이 유지된다. 조문 탐색은 기존 인용/역인용/문맥 확인 색상을 유지한다.

### 범위

국가계약법·지방계약법·조달사업법·전자조달법·판로지원법 및 하위 법령, 국가계약 특례 법령, 공기업·준정부기관 계약사무규칙을 수집한다. 재경부 계약예규와 국가계약 관련 선정 규정, 조달청의 입찰·계약·다수공급자계약·전자조달 등에 관한 명칭 필터에 맞는 자료, 선정한 지방계약 예규·고시를 추가한다.

모든 부처·공공기관·지자체의 계약규정을 전수 수집한 것은 아니다. 선언된 검색어마다 마지막 페이지까지 수집하고 수신 건수와 공식 건수를 대조한다. 중복 검색 결과는 공식 식별자·판본·명칭·소관기관이 일치할 때만 합친다.

법제처 목록 및 본문 API: `target=eflaw` / `target=admrul`. 목록의 `nw`는 각각 3 / 1이다. 공식 식별자, 시행일, 소관기관을 본문과 확인한다.

- [행정규칙 API 안내](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=admrulListGuide)
- [시행일 기준 법령 API 안내](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdListGuide)

### 미분석 5건

- 국가계약 관련 고시금액, 국가계약법 시행령 제72조제3항제2호의 공동계약 대상사업, 국제입찰에 의하는 지방계약 범위 고시: 본문은 확보했으나 장·절·항목 형식이어서 조문 연결 미분석.
- 지방자치단체 입찰 및 계약 집행기준, 지방자치단체 입찰시 낙찰자 결정기준: 이번 API 응답에 본문 텍스트가 없었다. 목록·판본 정보와 공식 첨부파일 접근 경로를 보존하며 **API 본문 미제공**으로 표시한다. 본문 수집·연결 분석을 완료했다고 표시하지 않는다.

별표는 법령 API가 제공하는 제목·메타데이터의 인용만 연결한다. 첨부파일의 표·수치·내용과 부칙, 장·절·항목의 구조 분석, 문구 유사성 및 법적 영향의 자동 판정은 이번 범위에 포함하지 않는다. 법령별 별칭·같은 조 등의 미해결 참조는 보류 목록에서 확인한다.

## 수집·재빌드

작업 폴더: `C:\Users\gscha\codexproject\FscLawGalaxy-Stage2`.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.collect_procurement_universe --stage inventory
.\.venv\Scripts\python.exe -X utf8 -m scripts.collect_procurement_universe --stage collect
.\.venv\Scripts\python.exe -X utf8 -m scripts.collect_procurement_universe --stage build
```

연속 실행은 `--stage all`. 단계별 재개는 같은 수집일 폴더를 사용한다. 인증은 기존 환경변수·프로젝트 로컬 설정·Windows 사용자 환경변수에서 재사용한다. 인증값을 명령 인수나 산출물에 넣지 않는다.

- 독립 출력: `output/procurement-universe/`.
- 활성 자료: `bundle.json`, 요약 `summary.json`.
- 중간 목록·본문: `staging/YYYYMMDD/`와 검증 해시가 있는 `body-cache/`.
- 이전 활성 자료: `history/`. 검증 통과 후 새 자료를 원자적으로 교체한다.
- 동시 실행 잠금: `collect.lock`. 잠금 충돌 시 기존 실행과 잠금을 건드리지 않는다.
- 이번 추가는 세법·금융법 자동 갱신 예약에 포함하지 않았다. 조달·계약은 위 수집 명령으로 갱신한다.

## 데이터·상태 분리와 재사용

조달·계약 화면은 전용 bundle만 읽는다. 데이터가 없으면 **조달·계약 데이터 미수집**으로 표시한다. 세법·금융법·지방세 데이터로 대체하지 않는다. 검색·선택·필터·본문 찾기는 `pc_`로 구분하며 계약 분야별로 별도 보관한다.

공통 `universe_builder`, 행정규칙 조문 어댑터, 인용·역인용 분석기, 원문 열람기, 3D 은하 렌더러를 재사용한다. `(계약예규)` 접두어 생략과 공식 약칭은 명시적인 자료별 이름 목록으로 연결한다. 기존 세법·금융법 자료는 다시 만들지 않는다.

## 검증

- 원문 근거 전체를 수집 본문 또는 별표 제목의 문자 위치와 대조했다.
- 국가계약법 제27조: 역인용 근거 110건. 다른 계약 분야의 근거 81건.
- 국가계약법 시행령 제26조: 역인용 근거 53건.
- 정부 입찰·계약 집행기준 제94조: 공사·물품·용역 일반조건과 조달청 일반용역계약특수조건의 역인용 4건.
- 기존 데이터 809개 해시 일치. 새 산출물 인증값 검사 통과.
- 조달 전용 오프라인 테스트 17개, 실제 화면 상태 테스트 2개, 공통 터치·음향 JS 테스트 19개 통과.
- 실제 앱 테스트에서 네 은하 검색 상태, 계약 분야 전환, 개정안 검토 메뉴 이동 후 업로드 위젯 유지, 원문 열람과 미분석 안내를 확인했다.
- 기존 세법 테스트가 갱신된 그래프를 갱신 전 원문과 대조하는 오류를 발견해 같은 bundle의 원문을 사용하도록 수정했다. 근거 일치 검증 조건은 유지하고 판본 기준일 일치도 확인한다.
- 브라우저 직접 시각 검증은 브라우저 제어 도구의 실행 환경 오류로 미실행. 서버 정상 응답과 Streamlit AppTest, 생성 HTML·팔레트·JS 검증으로 확인했다. 실제 휴대전화 기기 검증은 미실행.
