# 공개 웹 보안과 오프라인 유지

## 실행할 수 있는 코드 제한

메인 HTML은 같은 출처의 스크립트만 허용합니다. 지도와 독립 HTML의 인라인 스크립트는 빌드 때 계산한 SHA-256 해시로 허용합니다. 스크립트를 변경하면 해시도 다시 생성되므로 기존 배포 파일을 임의로 수정해서 재사용하지 않습니다. 소개문에도 별도 정책을 적용합니다.

외부 조회수 서비스는 `img-src`에서만 허용합니다. 법령 자료·서비스 워커·지도 iframe은 같은 출처로 제한합니다. 임의 객체 삽입, base URL 변경, 폼 전송, HTML 속성의 이벤트 코드는 차단합니다. 기존 레이아웃의 style 속성과 동적 스타일 때문에 CSS에는 `unsafe-inline`을 허용하지만 스크립트에는 허용하지 않습니다.

GitHub Pages에서 HTML meta로 제공하는 CSP에는 응답 헤더 방식과 차이가 있습니다. `frame-ancestors`와 보고 전용 정책은 meta로 적용할 수 없습니다. 이것을 전체 보안 감사의 대체물로 보지 않습니다.

## 문자열과 링크

공개 읽기 화면은 DOM의 textContent를 사용합니다. 지도 정보 패널에서 HTML 문자열로 출력하는 법령명·원문·근거·숫자 표시는 HTML 이스케이프를 거칩니다. 지도 공식 출처 링크는 https://www.law.go.kr만 허용합니다. 일반 읽기 창의 공식 출처는 여러 기관을 지원하기 위해 http/https를 허용하되 사용자명·비밀번호가 포함된 주소와 javascript/data 등의 실행 주소는 차단합니다. 새 창에는 noopener/noreferrer를 적용합니다.

내려받는 검토자료 HTML에는 스크립트 실행을 허용하지 않습니다. 마루부리 파일을 포함할 때는 저작권·OFL 고지 전문도 함께 넣고, 고지를 읽을 수 없으면 글꼴을 포함하지 않고 기본 글꼴로 표시합니다.

## 변경 검증

- `scripts.test_web_security`: 메인·지도·독립 HTML·소개문 정책, 스크립트 해시, 개행 차이, 스크립트 종료 문자열 주입, 메시지 출처 검증.
- Node 읽기·신고·저장·서비스 워커 테스트: 입력 이스케이프, URL 제한, 오프라인 자료 검증과 보존.
- 실제 브라우저 확인: CSP 아래 조문 선택·지도·본문 창·검토자료 다운로드, 모바일 레이아웃, 기존 자료 저장 후 업그레이드/오프라인 열람.

가독성 포맷은 Prettier 3.6.2와 루트 `.prettierrc.json` 기준입니다. 템플릿을 수정할 때 `PUBLIC_MAP_*` 빌드 표식을 유지합니다. 예시: `npm exec --yes --package=prettier@3.6.2 -- prettier --write "web/*.mjs" "ui/assets/law_galaxy.html" "ui/assets/law_galaxy_gestures.js"`.
