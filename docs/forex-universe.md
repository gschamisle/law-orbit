# 외환 은하 (별도 미리보기)

기존 7개 분야의 수집 파일을 유지하면서 추가한 독립 분야입니다. 현재 메뉴에서는 관세·통관 다음에 배치합니다. 공개 사이트에는 아직 배포하지 않았습니다. 외환은 수집 본칙 중 식별 가능한 조문 전체를 분석하며, 업무 태그로 원문을 제외하지 않습니다.

## 범위와 수집 결과

2026-09-21 수집: 14종, 분석 조문 652개, 내부 인용 근거 1,748건, 미수집 외부 인용 329건, 상대 참조·대상 조문 등 확인 후보 53건. 근거 건수는 고유 법령 쌍 또는 개정 의무의 수가 아닙니다.

- 법제처 API: 외국환거래법·시행령 2종.
- 법제처 API 행정규칙 8종: 외국환거래규정, 외국 금융기관의 외국환업무에 관한 지침, 외국환업무전문인력교육에관한규정, 외환정보집중기관의 운영에 관한 규정, 외국환감독업무시행세칙, 외국환거래당사자에 대한 제재규정, 외국환거래의 검사 및 제재에 관한 훈령, 환전영업자 관리에 관한 고시.
- 한국은행 공식 법규정보 PDF 4종: 외국환거래업무 취급세칙·취급절차, 외환정보집중기관 운영세칙·운영절차.

한국은행 자료는 공개 조문 API를 전제로 하지 않습니다. [공식 법규정보](https://www.bok.or.kr/portal/singl/law/listSearch.do?menuNo=200200)에서 정확한 이름으로 최신 목록과 PDF를 자동 확인합니다. 목록 개정일·문서 ID·PDF 판본 ID·본문 개정 이력·마지막 부칙 시행일을 대조하며, 원본 PDF와 추출 텍스트, 해시를 별도 보존합니다. 두 쪽을 한 장에 인쇄한 운영절차 PDF는 왼쪽부터 오른쪽 순으로 읽습니다.

### 원문에서 발견된 두 가지 확인 사항

1. 외환정보집중기관 운영절차의 첫 쪽 개정 이력은 `2023.1.29.`이나 목록·마지막 부칙·[공식 개정 게시물](https://www.bok.or.kr/portal/bbs/P0002014/view.do?menuNo=200402&nttId=10081715)은 `2023.12.29.`입니다. 직접 대조한 파일의 ID·판본·SHA256이 모두 같은 경우에만 처리하고, 원문은 고치지 않습니다. 시행일은 마지막 부칙의 2024-01-01입니다. 다른 파일에서 날짜가 다르면 수집에 실패하도록 유지합니다.
2. 외환정보집중기관 운영세칙의 `제32조2` 표기 한 곳은 정규 조문번호로 추정하지 않습니다. 앞 제32조에 합치지 않고 **미분석 원문**으로 분리하며, 해당 문서 화면에서 펼쳐 볼 수 있습니다. 분석 652개에 포함하지 않습니다.

## 화면과 분석

- 기본체계, 지급·송금, 자본거래, 외국환업무·시장, 보고·검사 복수 태그. 조문 제목·본문의 키워드 분류이며 법적 적용 범위 판정은 아닙니다.
- 전체 지도는 법령·규정 14개와 실제 분석한 조문 652개의 점입니다. 큰 별의 색은 법령 묶음, 작은 점의 색은 첫 업무 태그입니다. 연결선에는 저장한 인용 근거가 있어야 합니다.
- `제7-1조`와 `제7조의1`을 구분합니다. 법/영/규정/세칙 같은 별칭은 원문의 명시적 정의에 따라 연결합니다.
- 직접 인용·역인용과 원문 근거·시행일·공식 링크를 확인합니다. 연결 조문 클릭은 본문 읽기 창을 열며, 중심 조문 변경은 별도 버튼입니다.
- 정적 공개판에서는 업무별 조문 선택 목록도 필터링합니다. 다른 업무로 이어지는 조문은 목록에서 삭제하지 않고 ‘분야 밖 관련 조문’으로 표시합니다.
- 브라우저 상태, 압축 자료 ID, 출력 폴더를 외환용으로 분리합니다. 다른 은하의 원문을 자동 합치지 않습니다.

## 한계

전 외환 관련 규범의 완전 수집은 아닙니다. 별표·서식 본문, 부칙의 인용, 문언 없는 의미상 관계는 미분석입니다. 상대 참조나 수집 판본에 없는 조문은 확인 후보로 남깁니다. 미수집 외부 법령은 인용 사실과 공식 링크를 남기고 본문·역인용 점검으로 표현하지 않습니다. 한국은행 첨부 형식이 바뀌면 수집기가 중단될 수 있습니다. 삭제·연혁·경과조치의 법적 판단을 대신하지 않습니다.

## 실행

프로젝트에서 `uv sync`로 의존성(pdfplumber 포함)을 준비합니다. 기존 `LAW_API_KEY`/`LAW_OC` 또는 로컬 설정을 재사용하며, 인증값과 출력 자료는 Git에 넣지 않습니다.

```powershell
uv run python -m scripts.test_forex
uv run python -m scripts.collect_forex_universe --stage inventory
uv run python -m scripts.collect_forex_universe --stage bodies
uv run python -m scripts.collect_forex_universe --stage build
```

단계가 다른 날짜에 이어지면 세 단계에 같은 `--date YYYYMMDD`를 명시합니다. 원본과 검증 전 자료는 `output/forex-universe/staging/<날짜>/`, 검증 완료 자료는 `output/forex-universe/bundle.json`입니다. 요약은 `summary.json`, 가장 최근 성공 단계는 `last-run.json`, 마지막 실패 이력은 `failure.json`에 기록합니다. 기존 잠금은 임의 삭제하지 않으며 검증 실패 시 이전 번들을 유지합니다. 이전 성공 자료가 있으면 교체 전 `history/`에 보관합니다.

주간 자동 갱신은 아직 이 분야에 연결하지 않았습니다.

### 기존 공개 자료를 보존한 정적 미리보기

```powershell
uv run python -m scripts.build_forex_site --base-site output/static-property-preview-v2 --destination output/static-forex-preview
uv run python -m http.server 8513 --bind 127.0.0.1 --directory output/static-forex-preview
```

대상 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 새 이름을 사용하세요. 원래 7개 분야의 manifest 항목을 유지하고, 압축 자료 무결성과 전체 배포 크기를 검증합니다. Streamlit은 기존 실행 방식의 법령은하 메뉴 내 ‘외환’에서 확인합니다.

## 검증

- 외환 단위·실제 자료 테스트 21개: 출처·판본 불일치 거부, 잘못된 번호 분리, 한국은행 실제 인용과 역인용, 하이픈 조문, 브라우저/공통 엔진 결과 대조 등.
- 전체 오프라인 46개 모듈 통과. 기존 Streamlit 통합 테스트 11개는 작업 폴더에 해당 자료가 없어 미실행입니다. 기존 수집 폴더를 읽기 전용으로 지정한 정적 사이트 검증 6개는 모두 통과했습니다.
- 기존 7개 분야 데이터 manifest 동일 및 정적 파일 해시 검증 통과.

모바일 폭 390×844와 데스크톱 1280×900, 한국은행 인용 근거·본문, 분야별 검색 상태, 저장 완료를 브라우저에서 확인했습니다. 실제 휴대전화 터치와 인터넷을 끊은 재접속은 미실행입니다. 상세 검증 기록은 `output/forex-universe/verification.json`입니다.

커밋·푸시·공개 배포는 별도 진행합니다.
