# 의료 — 의료기관 개설·운영

2026-09-28 공개 베타에 추가한 범위이다. 의료 전반을 망라하기보다 **개설·시설·인력·진료지원의 근거를 조문과 별표에서 함께 읽는 것**을 첫 범위로 정했다.

## 수집·분석 범위

- 의료법·간호법과 각각의 시행령·시행규칙: 6건
- 간호사의 진료지원업무 수행에 관한 규칙: 1건
- 간호사의 진료지원업무 수행행위 목록 고시: 1건
- 합계 **8개 문서, 492개 조문**. 법제처 API에서 현행 본문을 직접 수집했다.
- 의료법 법령군의 보건복지부·질병관리청 공동 소관은 실제 목록 응답과 대조했다. 다른 문서를 이름만으로 수집 대상에 넣지 않는다.

선정 별표는 **의료법 시행규칙 별표 3·4·5, 진료지원업무 목록 고시의 번호 없는 별표**이다. 칸·문단 266개를 분석했으며, 수집 범위 안을 향한 인용 위치 12곳과 외부 법령을 향한 14곳을 보존했다. 이는 서로 다른 법령·조문 수나 개정 의무 건수가 아니다.

전체 그래프에는 내부 인용 근거 1,154건, 외부 인용 근거 343건, 미해석 기록 70건이 있다. 문맥 확인 후보도 포함하므로 정확도 평가 수치로 사용하지 않는다.

## 화면에서 확인하는 방법

1. 분야별 법령에서 **의료**를 선택한다. 헌법의 별도 최상단 배치와 기존 분야 순서는 유지한다.
2. 기본 사례인 **의료법 제43조**를 연다. 시행규칙 별표 5가 제1·2·3항을 인용한 9곳을 역인용 목록에서 확인한다.
3. 별표 근거의 **본문 보기**를 누르면 지도와 검토 기준을 유지한 채 별표 본문이 열린다. **인용 위치**로 해당 칸의 문구를 강조한다.
4. 의료법 시행규칙의 법령 정보 아래 **별표·서식** 목록에서 다른 별표도 선택할 수 있다. 분석하지 않은 자료에는 본문 미분석과 공식 파일 링크가 표시된다.
5. 인용 근거를 선택해 **검토자료 내려받기**를 누르면 별표 본문·인용 위치·판본·출처를 HTML에 담는다. CSV는 근거표이다.

로컬 Streamlit에도 의료 메뉴와 별표 본문 읽기·텍스트 내려받기를 추가했다. 정적 웹과 같은 수집 자료를 사용한다.

## 원문 검증과 갱신

검증 표본은 `output/medical-annex-feasibility-20260928/`에 있다. 수집기는 새 API 응답과 검증 표본의 XML 트리 전체(태그·속성·본문·순서)를 대조한다. XML 선언·들여쓰기 차이를 허용하지만 내용 변경은 허용하지 않는다. 별표 제목·공식 파일 URL도 일치해야 한다.

HWP/HWPX를 다시 추출한 후 원본 파일 해시, 추출 본문 해시, 각 인용 문구의 시작·끝 위치를 검사한다. **새 판본이 기존 표본과 다르면 실패하며 이전 표본을 새 본문에 붙이지 않는다.** 따라서 아직 무인 주간 갱신 대상으로 등록하지 않았다. 판본이 바뀌면 새 별표 원본을 수집·검증하는 절차가 필요하다.

기존 환경변수 또는 로컬 설정의 인증값을 사용한다. 인증값·수집 캐시는 Git에 넣지 않는다.

```powershell
python -m scripts.collect_medical_universe --stage inventory
python -m scripts.collect_medical_universe --stage bodies
python -m scripts.collect_medical_universe --stage build
```

결과는 `output/medical-universe/`에 저장한다. 새 작업 환경에는 검증 표본을 먼저 준비해야 한다. 표본 검증은 `python -m scripts.verify_medical_annexes`를 사용한다.

기존 분야 자료를 보존하면서 의료만 추가한 미리보기:

```powershell
python -m scripts.build_labor_site --domain medical --base-site output/static-foundations-preview-20260928 --destination output/static-medical-preview-20260928
python -m http.server 8544 --bind 127.0.0.1 --directory output/static-medical-preview-20260928
```

이미 존재하는 출력 폴더에는 빌드하지 않는다. 다시 빌드할 때에는 새 이름을 지정한다.

## 검증

- 의료·별표·조달·공통 분야·헌법·노동·화면 구성 Python 테스트 78개 통과. 전체 오프라인 스위트 60개 모듈 통과(자료 부재로 건너뛴 검증은 로그에 구분).
- 별표 읽기·기존 연결 읽기·조회수·분야 간 연결·저장·위임·공공기관 JavaScript 테스트 55개 통과.
- 정적 웹 테스트 5개 통과, 실제 국세 번들 대조 1개는 이 저장소의 `output/tax-universe/bundle.json` 부재로 미실행.
- 정적 배포 묶음의 전체 구조·참조·해시·별표 인용 위치 검증 통과.
- 기존 분야 메타데이터 및 논리 자료 파일 20,153개의 바이트가 원본 미리보기와 일치함을 확인.
- 의료와 조회수 표시를 포함한 최종 묶음: 5,640개 파일, 184,593,830바이트. 의료 자료와 조회수 기능은 기존 헌법·노동 미리보기보다 26개 파일·약 0.55 MB 증가했으며, 최종 소개문에는 원본 표지 이미지를 추가했다.
- 브라우저에서 의료법 제43조 → 정원표 역인용, 인용 위치 강조, 기준 조문 유지, 별표 미분석 안내, HTML 자료 생성 확인. 브라우저 자동 다운로드 완료 이벤트는 확인하지 못했으며 생성 완료 및 내려받기 링크까지 확인했다.
- 모바일 너비에서 별표 읽기 창의 가로 넘침 없음 확인. 실제 휴대전화 터치 조작 검증은 미실행.

## 한계와 다음 범위

- 본문 분석한 별표는 선정 4개뿐이다. 나머지는 제목·원본 링크와 미분석 상태만 제공한다.
- 표의 '종합병원과 같음' 같은 내부 참조, 병합 칸의 기관별 귀속, 인력·면적 산식과 적용조건은 자동 판정하지 않는다.
- 표는 칸·문단 순서로 읽는다. 법적 적용 판단에는 공식 표의 배치와 조건을 함께 확인해야 한다.
- PDF·이미지 전용 별표, 건강보험 수가·급여, 약사·의료기기·감염병 전 영역은 이번 범위 밖이다.
- 의료행위의 적법성, 개설 허가 가능 여부, 적정 인력 수를 자동 판단하는 도구가 아니다.

추출기와 읽기 창은 공통 엔진이지만, 다른 분야의 별표는 원문을 검증한 뒤 개별적으로 적용해야 한다.
