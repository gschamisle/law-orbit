# 무료 웹 법령 은하

**[공개 열람 사이트](https://gschamisle.github.io/tax-amendment-assistant/)** — 설치 없이 브라우저에서 엽니다.

기존 Streamlit 앱을 유지하면서 브라우저에서 동작하는 별도 열람 버전을 제공합니다. API 서버·데이터베이스·법제처 인증값·문서 업로드가 필요하지 않습니다.

## 기능

- 국세, 조달계약, 금융, 지방세, 국토건축주택, 환경화학안전의 독립된 은하
- 법령명·약칭 선택, 선택 법령의 본문 검색, 조문 목록에서 불러오기
- 조·항·호·목 번호 입력과 저장 인용 범위 대조
- 조문 본문·시행일·공식 출처, 직접 인용·역인용 근거
- 연결 조문 클릭은 별도 본문 읽기 창을 열며 기존 검토 기준과 은하를 유지합니다. `이 조문을 중심으로 탐색`을 눌러야 탐색 기준이 바뀝니다.
- 법령 전체 참조는 읽기 창에서 조문을 고를 수 있으며, 수집 판본에 없는 조문을 다른 조문으로 대체하지 않습니다.
- 금융 업권과 다른 분야의 복수 태그 필터, 분야 밖 관련 조문 표시
- 지방세 지역별 조례·규칙과 중앙 법령에 대한 전국 수집 후보의 역인용
- 법령별 오프라인 저장. 연결 대상의 본문은 해당 법령을 열 때 내려받습니다.
- 기존 MaruBuri/Pretendard, 3D 은하, 터치 회전·확대, 선택형 소리 재사용

시각화는 성능을 위해 최대 180개 연결 대상을 표시하고, 인용 근거 목록은 페이지 단위로 전부 열람합니다. 조문 범위 해석은 기존 Python 파서가 생성한 구조와 브라우저의 범위 비교를 사용하며 양쪽 결과를 대조하는 테스트가 포함됩니다. 신설 항의 적용 취지 추론·개정안 업로드 검토·의미 유사성 분석은 로컬 앱에 남습니다. 미수집 법령은 원문 링크와 미수집 상태를 유지합니다.

## 생성·실행

```powershell
python -m scripts.build_static_galaxies --source-root C:\Users\gscha\codexproject\FscLawGalaxy-Stage2 --destination output/static-site
python -m scripts.validate_static_galaxies output/static-site
python -m http.server 8504 --bind 127.0.0.1 --directory output/static-site
```

브라우저에서 `http://127.0.0.1:8504/`를 엽니다. HTTP(S)로 제공해야 하며 `index.html` 파일을 단순히 더블클릭하는 방식은 지원하지 않습니다. 기존 `output` 자료를 읽기만 하고, 이미 있는 출력 폴더는 덮어쓰지 않습니다. 수집 자료가 빠지면 다른 분야로 대체하지 않고 생성을 중단합니다.

생성 결과를 GitHub Pages 또는 Cloudflare Pages에 올릴 수 있습니다. 게시용 자료는 고정 체크섬이 있는 압축 파일로 나누고 브라우저에서도 검사합니다. 파일마다 25MiB 미만, 전체 20,000개 이하 및 GitHub Pages 전체 1GiB 미만인지 검증합니다. 생성물에는 API 키·환경설정·업로드·수집 로그를 넣지 않습니다.

## 오프라인과 갱신

처음에는 인터넷 연결이 필요합니다. 화면·서체는 서비스 워커로 저장하고, 법령 자료는 검증 후 브라우저 캐시에 보관합니다. 선택 법령의 모든 연결 근거를 보관하려면 **이 법령 오프라인 저장**을 누릅니다. 시크릿 모드, 저장 공간 부족, 브라우저의 자동 정리로 저장되지 않거나 삭제될 수 있습니다. 저장하지 않은 법령까지 오프라인으로 열람할 수 있다고 표시하지 않습니다.

수집·분석은 운영자 기기에서 수행합니다. 새 수집판으로 정적 자료를 다시 생성·검증·게시하면 사용자는 **새 판본 확인**으로 갱신할 수 있습니다. 기존 Codex의 노트북 갱신 예약이 무료 웹 배포까지 자동으로 수행하는 것은 아닙니다. 정적 파일의 해시는 판본별로 달라져 서로 다른 판본의 조문과 연결 자료를 섞지 않습니다.

## 테스트

```powershell
$env:STATIC_SOURCE_ROOT='C:\Users\gscha\codexproject\FscLawGalaxy-Stage2'
python -m scripts.test_static_galaxies
```

Node.js는 개발 시 Python/JavaScript 결과 비교에만 사용하며 이용자의 기기에는 설치하지 않습니다. 범위·가지조문·문맥 확인·법령별 상태와 자료 분리, 실제 수집판의 인용 결과를 검증합니다. 무료 호스팅 정책은 변경될 수 있으며, 무료 사용 한도를 초과하면 배포 방식을 재검토합니다.

## 검증한 수집판

2026-09-19에 생성한 공개 묶음: 11,036개 문서, 241,524개 조문입니다. 원천 수집일·시행일은 자료별로 다르며 화면에 표시합니다. 정적 자료 18,516개, 약 142.7MiB이며 가장 큰 단일 자료는 약 388KiB입니다. 이용자는 전체 묶음을 한 번에 다운로드하지 않습니다.

새 웹 테스트 6개와 기존 오프라인 회귀 테스트 44개 모듈이 통과했습니다. GitHub의 Linux 빌드에서도 고정한 압축 묶음과 모든 파일 참조·체크섬·웹 코드 일치를 확인합니다.

실제 자료의 국세·금융·조달계약·국토건축주택·환경화학안전 인용 결과를 기존 엔진과 대조했습니다. 지역별 동일 명칭의 문서를 별도 ID로 유지하며, 지방세법에서 강릉시 조례로 이어지는 본문 이동을 브라우저에서 확인했습니다. 법인세법을 저장한 후 미리보기 서버를 중지하고 새로고침하여 다른 조문과 인용 근거를 열람했습니다. 모바일 너비 390px의 배치를 점검했으며 실제 휴대전화 기기 테스트는 별도입니다.

## GitHub Pages 게시

`codex/static-galaxies` 브랜치의 공개 웹 코드를 유지합니다. 기존 main과 Streamlit 앱은 변경하지 않습니다. 게시용 압축 묶음은 GitHub Release에 저장하고 `static-web-release.json`에 URL·SHA-256·자료 판본을 고정합니다. Pages 작업은 묶음을 다운로드하여 체크섬과 모든 자료 참조를 검증한 뒤 배포합니다. 업로드 자료·API 인증값을 전달하는 단계는 없습니다.

갱신할 때 새 수집 자료로 생성·검증하고 새 Release의 묶음과 메타데이터를 함께 갱신하세요. 웹 코드만 바꿔도 묶음을 다시 만들어야 합니다. 무료 Pages의 사용 한도 안에서는 상시 서버 비용이 발생하지 않으며, 트래픽 한도는 GitHub 정책을 따릅니다.

### 연결 조문 읽기 검증

`node --test scripts/test_reading.mjs`로 같은 법령 본문 재사용, 다른 법령 본문 조회, 미수집 조문 비대체, 법령 전체 참조, 지역별 자료 분리, 잘못된 자료 식별의 6개 테스트를 실행합니다. 공개 배포 작업에도 포함합니다.

브라우저에서 법인세법 제32조의 연결 제60조를 열어도 기준 조문과 연결 12건이 유지되고, 명시적으로 탐색 버튼을 누를 때만 제60조로 전환되는 것을 확인했습니다. 지방세법 제4조에서 강릉시 조례 본문을 열어도 전국 검토 범위를 유지합니다. 작은 화면 너비와 미리보기 서버 중지 후 저장된 조례 본문 열람도 확인했습니다.
