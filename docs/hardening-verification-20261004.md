# 2026-10-04 공개 웹 보강 검증

## 적용 범위

오래된 앱 화면 캐시의 안전한 정리, 실행 코드 제한(CSP), 표시 문자열·링크 확인, 글꼴 고지 포함, 시험 목록과 CI 재현성, 명칭·문서·소스 가독성을 보강했습니다. 법령 재수집이나 인용 그래프 변경은 포함하지 않았습니다.

기존 공개판 `static-web-2026-09-29-v7`을 기반으로 화면 파일만 갱신했습니다. 자료 파일 5,947개와 manifest는 바이트 단위로 동일하며, 공개 사이트 파일 수도 5,980개로 동일합니다. 새 자료 버전을 수집한 것으로 표시하지 않습니다.

## 자동 검증

| 구분 | 결과 |
|---|---|
| 오프라인 Python | 70개 실행 명령 정상 종료. 자료 의존 사례 2개는 명시적으로 건너뜀 |
| 오프라인 Node | 12개 모듈, 108개 시험 통과 |
| 수집자료 Python | 2개 시험 통과, 별도 로컬 스냅샷 부재로 15개 건너뜀 |
| 새 공개 자료 대상 Node | 2개 모듈, 12개 시험 통과 |
| 의존성 잠금 파일 | `uv lock --check --offline` 통과 |
| 공개 자료 검증 | 압축 목록·해시·자료 구조·원본 대비 동일성 확인 |

Python 오프라인에서 건너뛴 항목은 로컬 금융 자료를 요구하는 화면 시험과 별도 국세 수집 폴더를 요구하는 통합 사례입니다. 별도 수집자료 시험에서는 조달 2개, 국토·건축·주택 4개, 환경·화학·안전 4개, 공공기관 범위 5개가 건너뛰어졌습니다. 이를 통과한 것으로 집계하지 않습니다. 외부 AI/API 전용 시험은 실행하지 않았습니다.

## 브라우저 검증

격리된 Chrome 환경에서 다음 동작을 확인했습니다. 공개 조회수 서비스는 호출하지 않았습니다.

- 국세 → 법인세법 제16조 선택, 49개 연결 표시, 관련 조문 본문 창 열기.
- 선택한 근거의 검토자료 HTML 생성과 글꼴 고지 포함.
- 이전 공개판에서 자료 저장 후 새 판으로 전환: 이전 화면 캐시는 삭제되고 자료·목록 캐시는 유지됨.
- 네트워크를 끈 뒤 재열기: 저장된 법인세법 본문과 지도 표시.
- 허용하지 않은 인라인 스크립트가 CSP에 차단됨. 악성 HTML 형태의 시험 문자열은 요소로 실행되지 않고 문자로 표시됨.
- 320px 화면의 가로 넘침 확인. 터치 모드 시험에서 지도 조작/종료 전환과 세 버튼의 화면 내 배치 확인.

터치 조건은 시험 환경에서 재현한 것으로, 실제 휴대전화에서 직접 확인한 결과는 아닙니다. 소개문·독립 지도·공개 지도는 빌드 시 스크립트 해시를 적용하며, 줄바꿈 차이에 대한 회귀 시험도 포함합니다.
