# 고용·노동 — 법령과 절차의 연결

2026-09-28 공개 베타에 추가한 범위입니다.

## 수록 범위와 쓰임

근로기준법·기간제법에서 출발해 조문이 인용하는 법령과 해당 조문을 인용하는 시행령·시행규칙·규정을 함께 읽습니다. 기존 분야와 데이터·선택 상태는 분리하고 수집·인용 분석·본문 읽기·시각화 엔진은 재사용합니다.

- 적용범위·근로계약 / 근로시간·휴가 / 임금·퇴직급여
- 기간제·파견 / 차별·일가정 양립 / 해고·권리구제 / 노사관계
- 업무 질문 5개: 근로기준법 제11조·제60조·제28조, 기간제법 제4조·제9조
- 법령·조문·항호목은 수집 목록에서 선택합니다. 긴 법령명은 정식 명칭으로 표시합니다.
- 연결을 클릭하면 기준 조문을 유지한 채 본문을 읽습니다. 탐색 중심 변경은 별도 동작입니다.
- 조문에 여러 업무 태그를 붙이며 태그가 없는 조문은 전체 목록에 남깁니다. 분야 밖 관련 조문도 숨기지 않습니다. 태그는 탐색용이며 법적 적용 범위를 뜻하지 않습니다.

### 법률 10개와 각각의 시행령·시행규칙

근로기준법, 기간제 및 단시간근로자 보호 등에 관한 법률, 파견근로자 보호 등에 관한 법률, 최저임금법, 근로자퇴직급여 보장법, 남녀고용평등과 일ㆍ가정 양립 지원에 관한 법률, 노동위원회법, 노동조합 및 노동관계조정법, 임금채권보장법, 근로자참여 및 협력증진에 관한 법률.

### 선정 행정규칙 4개

근로감독관집무규정, 노동위원회규칙, 평균임금산정 특례 고시, 고용노동관계법 위반자에 대한 과태료 부과·징수업무에 관한 예규.

법령명과 실제 API 소관부처를 모두 검증합니다. 남녀고용평등법 법률군은 고용노동부·성평등가족부 공동 소관 응답을 확인해 해당 법률군에 한하여 허용합니다. 다른 부처의 동명 유사 자료는 자동 수록하지 않습니다.

`통상임금 산정지침`은 선언한 명칭·소관 조건으로 이번 API 목록 조회에서 확인되지 않아 미확보로 남겼습니다. 해양수산부의 유사 명칭 지침을 대신 넣지 않았습니다.

## 실제 수집 및 검증

2026-09-28 기준 법제처 API 목록 조회 → 본문 수집 → 그래프 생성을 완료했습니다.

| 항목 | 건수 |
|---|---:|
| 법령·규정 | 34 (법률·시행령·시행규칙 30, 행정규칙 4) |
| 조문 분석 문서 | 34 |
| 수집 조문 | 1,494 |
| 내부 인용 근거 레코드 | 3,012 |
| 외부 인용 근거 레코드 | 793 |
| 미해결 해석·연결 문제 | 119 |

레코드 수는 서로 다른 법령 쌍이나 개정 필요 건수가 아닙니다. 범위 인용·반복 인용·문맥 확인 후보가 포함됩니다. 자료 무결성 검사 통과는 전체 인용 정확도나 누락률 검증을 뜻하지 않습니다.

실제 확인 사례:

- 기간제법 제4조 ← 시행령 제3조제1항: `법 제4조제1항제5호`
- 기간제법 제9조 ← 노동위원회규칙 제100조: `기간제법 제9조제1항`
- 기간제법 제9조 ← 노동위원회규칙 제17조제1호: `기간제법 제9조에서 제15조까지`
- 근로기준법 제28조 ← 노동위원회규칙 제16조제2호: `「근로기준법」 제28조`

미리보기는 기존 12개 분야의 카탈로그와 논리 자료 19,947개의 바이트가 그대로임을 대조했습니다. 전체 5,560개 파일, 약 180 MB이며 기존 압축본 대비 68개 파일·약 1.3 MB 증가했습니다. 최종 파일 수·크기·경로·해시·도메인 검증을 통과했습니다.

## 실행

프로젝트 Python 환경에서 실행합니다. 기존 로컬 인증 설정을 재사용하며 키를 명령 인자나 Git에 넣지 않습니다.

```powershell
python -m scripts.collect_labor_universe --stage inventory
python -m scripts.collect_labor_universe --stage bodies
python -m scripts.collect_labor_universe --stage build
python -m unittest scripts.test_labor scripts.test_labor_ui

# 이미 검증된 공개 자료에 고용·노동을 별도 출력으로 추가
python -m scripts.build_labor_site --base-site output/static-review-packed-final --destination output/static-labor-preview-new
python -m http.server 8542 --bind 127.0.0.1 --directory output/static-labor-preview-new
```

출력: `output/labor-universe/`. 자료가 없으면 고용·노동 데이터 미수집을 표시하며 다른 분야의 그래프를 대신 읽지 않습니다. 기존 MOFE 일괄 수집 명령의 대상은 변경하지 않았습니다.

## 범위 밖과 한계

- 고용보험·고용지원사업·산업안전·산재보험은 이번 수집 범위 밖입니다.
- 판례·행정해석·단체협약·취업규칙·개별 노동위원회 판정은 미수집입니다. 근로자성, 갱신기대권, 통상임금, 해고 정당성 등을 자동 판정하지 않습니다.
- 별표 제목과 관련 조문 연결은 포함하지만 **고용·노동의 별표 본문은 미분석**입니다. 앞서 보완한 별표 분석 엔진을 이 분야에 적용·검증한 것으로 표시하지 않습니다.
- 선택한 자료의 시행예정 판본은 이번 조회에서 반환되지 않았습니다. 전체 고용·노동 분야에 예정 개정이 없음을 뜻하지 않습니다.
- 외부 법령의 인용은 원문과 공식 링크를 보존하지만, 미수집 본문과 역인용까지 점검했다고 표시하지 않습니다.
- 정기 자동 갱신 예약은 아직 추가하지 않았습니다. 별도로 추가한 [헌법](constitution-universe.md)은 독립된 자료와 화면 상태를 사용합니다.
