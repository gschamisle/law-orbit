# 국고·회계 문단 인용과 조달계약·공공기관 연결

2026-09-23 공개판에 포함하는 국고·회계·조달계약 문단 분석과 조달계약·공공기관 연결의 구현·검증 기록입니다.

## 달라진 점

- 국고·회계 지침 20건, 조달계약 고시 3건의 확보된 본문에서 명시적 인용을 분석합니다.
- 문단 번호는 `1. (목적)`처럼 원문 위치로 표시합니다. 문단을 가상의 `제1조`로 바꾸지 않습니다.
- 지침에서 근거 조문을 읽고, 대상 조문에서는 해당 지침의 역인용을 확인합니다. 항·호 범위와 조 범위 인용은 기존 분석기를 사용합니다.
- 조달계약의 **공공기관 연결 포함**, 공공기관의 **조달계약 연결 포함**으로 다른 분야의 수집 본문을 읽습니다. 본문 열람은 현재 검토 조문을 바꾸지 않습니다.
- 분야별 전체 지도·법령 목록·선택 상태는 독립적입니다. 공통으로 이미 수집한 법령은 해당 분야의 판본을 유지하고 중복 연결을 추가하지 않습니다.
- 기존 외환·금융 연결과 국세·공공기관의 후속 개정 점검 자료는 유지합니다.

## 실제 확인 사례

1. 국고·회계 → 교환수익 회계처리지침 → 국가회계기준에 관한 규칙 제3조제2항 본문 보기.
2. 같은 규칙 제3조제2항 탐색 → 인용하는 지침 19건. 해당 항 범위를 유지해 대조합니다.
3. 조달계약 → 공기업ㆍ준정부기관 계약사무규칙 제1조 → 공공기관의 운영에 관한 법률 제39조 본문 보기.
4. 공공기관 → 공공기관의 운영에 관한 법률 제44조 → 국가계약법 제4조, 조달사업법 제14조 본문 보기.

## 수집 판본과 분석 범위

이번 작업은 공개판에 포함된 본문을 재분석했습니다. API 재수집이나 원문·법 시행 판본 갱신은 하지 않았습니다. 조달계약은 2026-09-19, 공공기관은 2026-09-21 수집 자료를 대조하며 개별 법령 시행일도 함께 표시합니다.

| 구분 | 문서 | 조문 특정 인용 | 문서 전체 참조 | 합계 |
|---|---:|---:|---:|---:|
| 국고·회계 문단 분석 | 20 | 103 | 113 | 216 |
| 조달계약 문단 분석 | 3 | 8 | 0 | 8 |
| 조달계약↔공공기관 | — | 127 | 31 | 158 |

문단 분석의 조문 특정 인용 중 **50건**은 같은 분야에 수집된 대상 조문 본문과 연결됩니다. 나머지는 외부 미수집 인용으로 보존합니다. 문서 전체 참조는 특정 조문 연결과 구분합니다. 건수는 인용 위치·대상별 근거 수이며 법령 수나 개정 의무 수가 아닙니다.

- 국고·회계의 대상 해석·판본 확인 16건은 확인 목록에 남겼습니다.
- 조달계약의 `지방자치단체 입찰 및 계약 집행기준`, `지방자치단체 입찰시 낙찰자 결정기준`은 본문이 없어 계속 미분석입니다.
- 분야 간 연결에서 `기타공공기관 계약사무 운영규정 → 국가계약법 제59조`는 수집 대상 조문이 없어 연결하지 않았습니다. 기존 미해결 인용은 보존합니다.
- 문단 내부 항목 간 참조, 이미지·표·별표·부칙 본문, 의미상 유사성은 이번 분석 범위가 아닙니다. 금액·회계처리의 적정성을 판정하지 않습니다.

## 구현과 재현

공정거래의 `core.ftc_text_citations`에 국고·회계·조달계약 문단 형식만 추가했습니다. `core.forex_finance_links`의 분석기와 기존 공개 웹 본문 읽기 기능에 조달계약·공공기관 쌍을 추가해 재사용합니다. 등록되지 않은 분야 조합과 판본 불일치는 거부합니다.

```powershell
python -m scripts.build_mofe_reuse_site --base-site output/static-ftc-public-v2 --destination output/static-mofe-reuse-final
python -m http.server 8531 --bind 127.0.0.1 --directory output/static-mofe-reuse-final
```

대상 폴더가 존재하면 덮어쓰지 않고 중단합니다. 재실행할 때는 새로운 미리보기 폴더명을 사용하세요. 보고서는 미리보기 폴더 옆 `*-report.json`에 저장합니다. Python 의존성은 프로젝트의 설치 환경을 사용합니다.

새 빌드는 실제로 참조되는 자료만 복사합니다. 원본 공개판의 압축 파일이나 수집 원문을 삭제·수정하지 않습니다. 국세 등 다른 10개 분야의 카탈로그와 기존 외환·금융 연결은 동일합니다.

- 새 정적 빌드의 모든 참조 파일·체크섬·문단 인용 원문 위치·대상 조문·분야 경계 검증 통과. 국세 등 다른 10개 분야 카탈로그, 기존 외환·금융 연결, 원본 배포 자료 보존을 확인했습니다.
